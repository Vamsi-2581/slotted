# Prose capability inventory

Produced before the family was designed or written, as
`.claude/skills/component/references/capability.md` requires. The family is new:
`docs/process/build-order.md` names **Prose** in the wave 1 preamble, defers it to the
end of wave 4 — behind `list`, `list-item` and `link`, which now exist — and
writes no scope paragraph for it. The paragraph derived from this inventory
lands in the same commit, as `docs/build-briefing.md` requires of a family whose
scope is missing.

Sources were read on 4 September 2026.

---

## 1. Surveyed

| Implementation                                | Called                                                                                                                                                        | Read at                                                                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `@tailwindcss/typography` (`main`)            | `prose`; `prose-sm`…`prose-2xl`; `prose-invert`; `prose-gray`…; element modifiers `prose-h1:`, `prose-a:`, `prose-table:` (26 targets); `not-prose`; `lead`    | <https://raw.githubusercontent.com/tailwindlabs/tailwindcss-typography/main/README.md>                            |
| shadcn/ui **Typeset**                         | `typeset`; presets `typeset-docs`, `typeset-chat`, `typeset-reading`; `--typeset-size`, `--typeset-leading`, `--typeset-flow`; `typeset-scroll`; `not-typeset` | <https://ui.shadcn.com/docs/typeset>                                                                             |
| Nuxt UI **Prose components**                  | `ProseH1`…`ProseH4`, `ProseP`, `ProseA`, `ProseCode`, `ProsePre`, `ProseTable`/`Thead`/`Tr`/`Th`/`Td`, `ProseStrong`; theme override under `ui.prose.*`        | <https://ui.nuxt.com/getting-started/typography>                                                                 |
| Primer / GitHub `markdown-body`               | `.markdown-body`, `.anchor`, `.footnotes`, task lists                                                                                                         | <https://raw.githubusercontent.com/primer/css/main/src/markdown/markdown-body.scss>, <https://github.com/sindresorhus/github-markdown-css> |
| WCAG 2.2 SC 1.4.12 Text Spacing (AA)          | line height 1.5×, paragraph spacing 2×, tracking 0.12×, word spacing 0.16× — set by the reader, with no loss of content                                        | <https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html>                                                  |
| WCAG 2.2 SC 1.4.8 Visual Presentation (AAA)   | 80 characters a line, leading at least 1.5, paragraph spacing at least 1.5× the leading                                                                        | <https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation.html>                                           |
| WAI-ARIA Authoring Practices, pattern index   | no pattern for editorial content; the closest published patterns are for widgets, not for a region of rendered text                                            | <https://www.w3.org/WAI/ARIA/apg/patterns/>                                                                      |

The four implementations disagree about what the thing **is**.

Tailwind bakes a type scale and a measure into the recipe, then hands back a
modifier API — twenty-six `prose-<element>:` variants — to undo them. Typeset
refuses both: no scale, no maximum width, and three custom properties instead of
a modifier language. Nuxt refuses the region entirely and ships one component
per element, configured through an application-level theme object. Primer writes
one hand-tuned stylesheet, in physical properties, with no configuration at all.

They agree on one thing, and it is the reason the family exists: the content is
**not authored element by element**. It arrives as a tree from a Markdown
renderer, a CMS, or a language model, and the application never gets to put an
attribute on the `h2`.

## 2. Table stakes

| Capability                                          | Who ships it                                        | Verdict                        | Reason                                                                                                                                                                                                                                        |
| --------------------------------------------------- | --------------------------------------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One region that styles unadorned descendants        | Tailwind, Typeset, Primer                           | adopt                          | The root carries `data-ui='prose'` and every rule descends from it. Nuxt's per-element components are refused below.                                                                                                                            |
| Zero-specificity guard around every content rule    | Tailwind, Typeset                                   | adopt                          | `:where()` costs nothing in specificity, so `[data-ui='link']` (0,1,0) inside the region beats prose's `a` rule (0,0,0) with no `!important` and no ordering trick. Both sources reach for it to lose to the consumer; here it also has to lose to thirty-odd sibling families. |
| An escape hatch for a subtree                       | Tailwind (`not-prose`), Typeset (`not-typeset`)     | adapt                          | The library's public selectors are `data-ui` and `data-part`, so the hatch is `data-part='exclude'`. A class would not be contract, and `identity.test.mjs` rejects one.                                                                        |
| Size steps                                          | Tailwind (5 classes), Typeset (`--typeset-size`)    | adapt                          | Three steps — `sm`, `md`, `lg` — reading `--slotted-font-size-*`. Tailwind's five sit on a scale of its own; this library already has one, and a second would be the parallel scale `docs/token-foundation.md` forbids.                          |
| Block rhythm as one control                         | Typeset (`--typeset-flow`), Tailwind (baked in)     | adapt                          | A `flow` axis of `tight`/`normal`/`loose` over the space scale. Typeset proves one number governs the whole page; the axis names the three useful values instead of asking every consumer to pick a length.                                     |
| Leading                                             | Typeset (`--typeset-leading`), Tailwind (baked in)  | adapt                          | Follows `--slotted-line-height-*` per step, retunable through `--slotted-prose-line-height`. Not an axis: leading that moves independently of size is how a page ends up with 1.3 leading on 16px text, under the 1.5 that SC 1.4.8 asks for.    |
| Dark mode                                           | Tailwind (`prose-invert`), Typeset, Nuxt, Primer    | adapt                          | Nothing to add. The family paints only semantic tokens, so `light`, `dark` and `high-contrast` are already answered; Tailwind needs a second hand-designed palette for one of the three.                                                        |
| A maximum measure                                   | Tailwind (`65ch`), Primer (`980px`)                 | decline → `container`          | `docs/build-briefing.md` decided it: measure belongs to `container`, and to it alone. `<Container size="measure"><Prose>…</Prose></Container>` is the composition. Typeset reached the same conclusion independently and gives the maximum to the layout.  |
| Per-element override                                | Tailwind (26 modifiers), Nuxt (`ui.prose.*`)        | adapt                          | The `:where()` guard means a consumer's own rule, utility, or Slotted family already wins with no API at all. The modifier language exists to defeat Tailwind's own specificity, which this family does not have.                               |
| Heading ladder and the space above a heading        | all four                                            | adopt                          | Space above a heading is larger than the space below it, so a heading binds to the text it introduces. Derived from `flow`, as Typeset derives it.                                                                                              |
| Lists, nested lists, markers                        | all four                                            | adopt                          | The native `::marker` is kept. `list-item` draws its own only because its row is a grid and CSS has no `display` that is both; an editorial `li` is not a grid, so removing the marker would cost the list semantics Safari drops with it.       |
| Blockquote                                          | all four                                            | adopt                          | `border-inline-start` and an inset, so a right-to-left document is the same component mirrored. Primer's rule is `border-left`.                                                                                                                 |
| Inline `code` and `pre`                             | all four                                            | adopt, and defer highlighting  | Prose paints the type, the ground and the inset. Syntax highlighting, a copy control, line numbers and a wrap toggle belong to `code-block`, wave 8 of `docs/process/build-order.md`.                                                                   |
| Tables                                              | all four                                            | adopt, and defer the behaviour | Prose paints the rhythm and the rules. Sorting, sticky headers, column resize and row selection belong to `table`, wave 6.                                                                                                                      |
| A wide block that scrolls instead of overflowing    | Typeset (`typeset-scroll`), Primer (`pre` overflow) | adopt, and extend             | `data-part='scroll'`. The extension is in Gaps: none of the four makes the scroller reachable by keyboard.                                                                                                                                      |
| Images, figures, captions                           | Tailwind, Primer, Nuxt                              | adopt                          | `max-inline-size: 100%`, `block-size: auto`, and a caption set in the muted tone one step down.                                                                                                                                                 |
| Thematic break                                      | all four                                            | adopt                          | A bare `hr` reads `--slotted-divider-*`, so the rule Markdown emits and the `divider` family are one theme decision rather than two.                                                                                                            |
| Links                                               | all four                                            | adopt                          | A bare `a` reads `--slotted-link-*`. A Markdown link and a `<Link>` on the same page are otherwise two colours for one idea.                                                                                                                    |
| `kbd`                                               | Tailwind (`prose-kbd`), Primer                      | adopt                          | Reads the `kbd` family's own tokens, for the reason above.                                                                                                                                                                                     |
| Trimming the outer margins of the region            | all four                                            | adapt                          | `> :first-child { margin-block-start: 0 }` only. Spacing runs one way, so nothing needs trimming at the end — which is also what makes the region stable while it streams.                                                                       |
| Colour themes for the text itself                   | Tailwind (`prose-gray`, `prose-slate`, …)           | decline → the scheme           | The region inherits `--slotted-text` and paints no body colour. A per-region palette is the thing three schemes and five tones remove; a consumer wanting muted body text wraps the region in `<Text tone="muted">` or sets the property.        |
| Per-element components                              | Nuxt                                                | decline → the renderer         | The consumer's Markdown renderer already maps a tag to a component (`components={{ a: Link }}` in MDX, the same map in `@nuxtjs/mdc`). A parallel set of thirty components inside this library would be a second renderer with no renderer.      |
| Task lists                                          | Primer                                              | decline → `checkbox`           | A checkbox in editorial text is a real checkbox: `<li><Checkbox checked readOnly /> …</li>`. Prose removing the marker from an `li` that holds one is two declarations, and they are in the stylesheet.                                          |
| Named presets                                       | Typeset (`typeset-docs`, `typeset-chat`)            | adapt                          | The axes are the preset, and the defaults provider sets them once for an application: `<ProseDefaults flow="tight">` in React, `provideProseDefaults()` in Angular. Typed, and not a class.                                                     |
| Footnotes section                                   | Primer                                              | adopt                          | `data-part='footnotes'`: small type, muted tone. It is what GitHub Flavored Markdown emits, and the rule is three declarations.                                                                                                                 |
| Heading anchors                                     | Primer (`.anchor`), Nuxt (`ProseH2` links)          | adopt                          | `data-part='anchor'`. The link is the consumer's — `rehype-autolink-headings` writes it — and prose owns its placement, its target size, and the rule that it appears on `:hover` **and** on `:focus-visible`. Primer's is reachable; Tailwind ships none. |

## 3. Differentiators

| Capability                                                     | Where it comes from                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stability while content is appended**                        | Typeset alone states it, and it is the capability a page rendering a language model's answer needs most. No `:last-child`, `:has()` or `:empty` in a layout rule, and spacing that runs one way only, so a block arriving at the end restyles nothing already on screen. Adopted, and held by a test rather than by care.                                                        |
| **Three schemes with no second palette**                       | This library's own foundation. `prose-invert` is a hand-designed dark palette Tailwind maintains beside the light one; here the tokens flip and the family writes nothing. `high-contrast` is a third scheme none of the four has at all.                                                                                                                                        |
| **A right-to-left document as the same component mirrored**    | Logical properties throughout, held by `logical.test.mjs`. Primer's `markdown-body` is written in `margin-left` and `border-left`; Tailwind's plugin mirrors part of its list indentation and none of its blockquote.                                                                                                                                                            |
| **One theme decision behind a Markdown link and a `<Link>`**   | The bare `a`, `hr` and `kbd` rules read the `link`, `divider` and `kbd` families' own tokens instead of inventing `--slotted-prose-link-color`. None of the four can do this, because none of them has the other families.                                                                                                                                                       |
| **The lead paragraph as a part, not a class**                  | Tailwind's `lead` is a class the consumer writes into the Markdown. `data-part='lead'` is contract, is selectable, and is what a renderer's component map can produce.                                                                                                                                                                                                          |
| **Defaults set once, per ecosystem**                           | Typeset's presets are classes; Nuxt's theme is one global object. Here it is a React context provider and an Angular injection token, so a value is typed, overridable per instance, and inherited by nesting.                                                                                                                                                                   |

## 4. Gaps

| Gap                                                                     | Verdict                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A scrolling block no keyboard can reach**                             | A `pre` or a `table` wider than the column scrolls sideways, and a reader with no pointer cannot scroll it: none of the four gives the scroller `tabindex`. Prose's `scroll` part takes `tabindex="0"`, `role="region"` and a name **only while it actually overflows**, measured through `@slotted/core/overflow`. A tab stop on a block that fits is a tab stop for nothing. |
| A single unbroken token — a URL, a hash, a base64 blob                 | `overflow-wrap: anywhere`, the form that also lowers the min-content size, so the token cannot widen a table cell or a grid track. The same reasoning `typography` already recorded.                                                                                                                                                                             |
| Content that does not start at `h1`                                     | A CMS body under a page title starts at `h2` or `h3`. No rule keys on the level of the first heading, and the first child's top margin is trimmed whatever element it is.                                                                                                                                                                                        |
| Two headings with nothing between them                                  | A section title followed immediately by a subsection. The space above a heading and the space below it are both stated, so the pair does not collapse into one block.                                                                                                                                                                                            |
| The reader's own text spacing (SC 1.4.12)                               | Line height 1.5×, paragraph spacing 2×, tracking 0.12× and word spacing 0.16×, applied by a user stylesheet, must lose no content. The family states no fixed `block-size` and no `overflow: hidden` on a text box anywhere.                                                                                                                                     |
| Forced colours                                                          | A code ground, a blockquote rule and a table rule are all decoration, and all three vanish when the operating system replaces the palette. The theme remaps the semantic tokens the family reads; what it cannot reach — a ground painted for contrast alone — is checked in the `high-contrast` capture and in the `forced-colors` emulation.                    |
| An empty region                                                         | A body that rendered to nothing must occupy nothing. Spacing lives on children, so an empty root is zero high.                                                                                                                                                                                                                                                   |
| Deeply nested lists                                                     | Past the third level the marker sequence repeats and the indentation runs out of column. The indent is inline-logical and stated once, and the capture at 240 pixels holds a three-level list.                                                                                                                                                                   |
| Announcing streamed content                                             | Declined, and named: a live region is the consumer's decision, because only the consumer knows whether the text is arriving once or continuously. `result-state` owns the announced region; prose is the typography under it.                                                                                                                                    |
| Sanitisation                                                            | Declined by `docs/component-features.md` section 10 in the family's own sentence: prose "não sanitiza conteúdo por conta própria". The renderer sanitises; a component that styled and sanitised would hide which of the two failed.                                                                                                                             |
