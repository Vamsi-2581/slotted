# `filter-bar` — capability inventory

Wave 8, round 11. Read on 2026-09-14, before any of this family's code was
written. `docs/component-features.md` §15 gives the family one paragraph —
search, quick filters, advanced filters, applied chips, a count, apply and
clear, presets, a state a URL can carry; priority fields inline on a wide
screen and a drawer on a narrow one; a clear that tells a current filter from a
required default — and §12 gives _Filter Builder_ another: typed rules per
field, AND/OR groups, presets, validation, serialisation, a readable
expression, rules removable by keyboard. `docs/process/build-order.md` wave 8 and
`docs/history/designs/2026-09-10-table-filter-design.md` §10 fold the second
paragraph into this family by name: conditions across several columns at once,
nested AND/OR groups beyond two conditions, presets, and one field that searches
every column.

The engine is already written. `@slotted/core/filter` holds the operator
vocabulary, the per-column descriptor, the predicate, the query-string codec
and the readable sentence, and `docs/build-briefing.md` binds every consumer to
it: **this family invents no vocabulary**. What it holds is the value one level
up — several columns, and groups of them — and the bar that edits it.

`docs/product/prd.md` names neither this family nor a filter; §40 asks whether a
dependency is warranted, and it is not: the engine exists and the rest is
composition of families the library already ships.

## 1. Surveyed

Eight sources, read 2026-09-14. They split on one question — **what the value
is** — and the split is the decision this family has to take:

- **A map of fields.** Polaris, PatternFly, Fiori, EUI and Carbon hold one
  filter per field, joined by AND across fields. What a field holds is the
  field's own.
- **A tree.** AG Grid's Advanced Filter, react-querybuilder and MUI X's filter
  panel hold rules with a combinator; the first two nest groups.

One specification was read for the keyboard and none for the bar as a whole,
because the APG index holds no filter pattern:

- [Toolbar Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/), for the
  row of controls: one tab stop, arrows between controls, and the text field
  exception — "if the toolbar includes a text box, arrow keys move the caret
  and not the focus" — which is the reason the search field is outside the
  roving row rather than inside it. The chip row is the layout-grid half of the
  [Grid Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/grid/), which
  `tags-input` already reads for the same row.

Inside this repository, five families were read for the boundary and not for
the survey:

- `table` edits one column's descriptor in its header, and its design records
  every line of the boundary this family inherits (§10 of the table filter
  design). The five typed filters and their operand controls are `table`'s
  files, which another lane may be editing; this family writes its own rule
  editor over the same engine.
- `@slotted/core/filter` holds the descriptor, and `parseFilter` refuses more
  than two conditions per column by design, with this family named as the
  reason. What is above the descriptor — several fields, groups of them, a
  global query — has no shape yet, and it is written here, in the engine, where
  `data-grid` will read it too.
- `tag` supplies the chip, worn as `data-ui` beside this family's own part, as
  `tags-input` and `multi-select` already do. `tag`'s `remove` is already
  floored at `--slotted-target-min`.
- `popover` and `drawer` supply the two surfaces a filter opens on — a pinned
  field's panel on a wide screen, the whole builder on a narrow one. Neither is
  rewritten.
- `page` publishes `--slotted-page-sticky-top`, and `docs/build-briefing.md`
  binds this family to read it for a sticky bar rather than measuring the
  header itself.

## 3. Differentiators

| Capability                                                              | Source                                            | What this library does with it                                                                                                                                                                                                                                                                                                                                              |
| ----------------------------------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The chip says the sentence the announcement says                        | Fiori's `filtersText`; `table`'s trigger name     | `describeFilter` already writes the sentence for `table`'s live announcement and the filtered trigger's accessible name; this family's chips, its collapsed summary and its `aria-label` on the bar all read from the same function, so a reader hears in the header what they read in the bar.                                                                              |
| One value, two editors                                                  | none of the eight — each owns its own model       | The first-level rule for a column _is_ the descriptor `table`'s header edits. A screen offers both, and either one moves the other, because there is one object.                                                                                                                                                                                                             |
| The count is announced                                                  | none                                              | PatternFly draws "10 of 17 items" and says nothing; here the `count` part is a polite live region, so a change in the filter is heard as its effect.                                                                                                                                                                                                                         |
| Three schemes, three densities, logical properties                      | the foundation                                    | The bar is `toolbar`'s geometry: control heights and gaps from the density scale, the drawer from the inline end under `dir="rtl"`, the chips' remove control at the inline end.                                                                                                                                                                                              |
| The URL form is readable                                                | AG Grid and MUI serialise JSON                    | `f=and(status~set~and~anyOf:paid,refunded|or(amount~number~and~greaterThan:100,customer~text~and~contains:ana))` — the per-column codec inside a group grammar of two characters, so a reader can read the address bar and a bookmark from an older version degrades to no filter rather than to an error.                                                                       |
| A required field keeps its default through Clear                        | Fiori alone checks required fields; none resets to a default | `docs/component-features.md` §15's own sentence, and the one behaviour a listing that must always be scoped to a tenant, a period or a status needs.                                                                                                                                                                                                                          |
| Angular sets the labels once                                            | the DI                                            | `provideSlFilterBarDefaults({ labels, apply, queryDelay })`, and `FilterBarDefaultsProvider` in React; the operator names are the same map `table` translates, so a product translates the vocabulary in one place.                                                                                                                                                         |

## 4. Gaps

| Gap                                                            | Who handles it                            | What this family does                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A field the value names and the consumer no longer declares    | nobody — AG Grid drops it silently        | A rule over an unknown field is kept in the value, drawn as a chip with the field's key and `data-invalid`, and removable; it is never evaluated. | Twenty applied chips                                           | PatternFly collapses per category with "n more" | The chip row wraps to two lines and then folds: `chipLimit`, default 6, and a "+n" chip that reveals the rest, `data-revealed` on the row. The folded chips stay in the DOM, as the briefing's truncation rule requires.                                                                                                                                                                       |
| A chip whose sentence is long — a set of eleven values         | nobody                                    | The chip truncates at `--slotted-filter-bar-chip-max`, carries the whole sentence in its `title` and its accessible name, and the sentence is what the builder shows when it opens on the chip.                                                                                                                                                                                             |
| A hostile string in an operand                                 | nobody                                    | Operands are text in text nodes, never markup; the URL codec escapes `~`, `(`, `)`, `|` and `,` with `encodeURIComponent` plus the two the function leaves alone.                                                                                                                                                                                                                            |
| The draft under `manual` when the value changes from outside   | Polaris `unsavedChanges` marks it and keeps it | A controlled value that changes while the draft is dirty replaces the draft and announces it — the application's value wins, which is the rule `docs/state-and-events.md` states for every controlled value.                                                                                                                                                                              |
