# OTP Input — inventário de capacidades

Família nova, onda 10 (`docs/process/build-order.md`). Escopo: valor único distribuído
em N caixas; comprimento, tipo numérico ou alfanumérico, colagem completa,
`autocomplete="one-time-code"`, máscara opcional; um input real, oculto, e as
caixas são pintura; `field` para rótulo e mensagem; `ControlValueAccessor` e
`name`. O inventário sai do campo antes de qualquer código, como
`.claude/skills/component/references/capability.md` exige.

Duas escolas: **um input** (input-otp e quem o embrulha) e **N inputs**
(Ark, Chakra, Mantine). O escopo já decidiu pela primeira: uma parada de foco,
uma entrada em `FormData`, um `<label>` real, um valor para o leitor de tela e
o autofill de SMS num campo só — `autocomplete="one-time-code"` só significa
algo num campo único (input-otp, README).

## 2. Table stakes

| Capacidade                                    | Quem entrega                                        | Veredito | Razão                                                                                                                                                                                                                                                        |
| --------------------------------------------- | --------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Comprimento                                   | todos                                               | adopt    | `length`, padrão 6. `maxlength` nativo no input.                                                                                                                                                                                                             |
| Valor controlado / não controlado             | todos                                               | adopt    | `value` / `defaultValue` / `onValueChange(value, request)`; razão `keyboard` para teclado, colagem, autofill e IME, o mesmo nome que `text-field` usa para a superfície de edição.                                                                              |
| Tipo numérico / alfanumérico                  | Ark, Chakra, Mantine, input-otp (`pattern`)         | adapt    | Eixo `type: numeric \| alphanumeric`, padrão `numeric`. Decide o conjunto aceite e o `inputmode`. `alphabetic` (Ark) fica fora: nenhum código de verificação real é só letras; `pattern` cobre-o.                                                             |
| Regex própria                                 | input-otp, Mantine (`type={/…/}`)                   | adapt    | `pattern: RegExp`, testada contra cada carácter; vence `type` no conjunto aceite e deixa o `inputmode` ao eixo.                                                                                                                                              |
| Colagem completa e parcial                    | todos                                               | adopt    | Nativa no input único; o filtro corre sobre o valor do elemento depois do `input`. Colagem no meio de um valor meio cheio é o comportamento do textbox.                                                                                                      |
| Transformação da colagem                      | input-otp, HeroUI (`pasteTransformer`)              | adapt    | `transform: (text) => string`, corrida antes do filtro em qualquer entrada — colagem, digitação, autofill. Remove hífens, põe em maiúsculas.                                                                                                                  |
| `autocomplete="one-time-code"`                | input-otp, Mantine (`oneTimeCode`), MDN             | adopt    | Padrão do atributo; o consumidor escreve outro valor nativo se quiser.                                                                                                                                                                                       |
| `inputmode`                                   | input-otp, Mantine, HeroUI                          | adopt    | `numeric` para `numeric`, `text` para `alphanumeric`; um `inputMode` explícito do consumidor vence.                                                                                                                                                          |
| Máscara                                       | Ark, Chakra, Mantine                                | adopt    | `mask`: o input passa a `type="password"` e a caixa pinta um ponto. A plataforma trata o valor como segredo — o leitor de tela não lê os dígitos, o sistema não os guarda no histórico do teclado.                                                              |
| Placeholder por caixa                         | Ark, Chakra, Mantine (`'○'`), input-otp             | adopt    | `placeholder: string`; um carácter repete-se, N caracteres distribuem-se. Padrão vazio: a caixa desenhada já diz que está vazia.                                                                                                                              |
| `onComplete`                                  | todos                                               | adopt    | `onComplete(value, event)` quando o valor atinge `length`. Emitido uma vez por preenchimento; apagar e completar de novo emite outra vez.                                                                                                                     |
| Submit automático                             | Ark, Chakra (`autoSubmit`)                          | adopt    | `autoSubmit`: `form.requestSubmit()` do form dono do input ao completar. Cada ecrã de 2FA real submete no último dígito.                                                                                                                                     |
| Blur ao completar                             | Ark, Chakra (`blurOnComplete`)                      | decline  | `onComplete={() => ref.current?.blur()}` são as linhas do consumidor.                                                                                                                                                                                        |
| Entrada rejeitada                             | Ark, Chakra (`onValueInvalid`)                      | adopt    | `onRejected(text, event)` quando o filtro descarta algo — a página diz "só dígitos" antes de o leitor tentar três vezes.                                                                                                                                       |
| Foco inicial                                  | Ark, Chakra, Mantine, HeroUI (`autoFocus`)          | adopt    | Atributo nativo `autofocus` no input; passa como qualquer outro.                                                                                                                                                                                             |
| Estados `disabled`, `readonly`, `invalid`, `required` | Ark, Chakra, Mantine, HeroUI                  | adopt    | Como `text-field`: não declarado, pergunta ao `field`; declarado, vence; `aria-required` e não `required` nativo.                                                                                                                                              |
| `name` e `form`                               | Ark, Chakra, Mantine, HeroUI                        | adopt    | Nativos no input único; uma entrada em `FormData`. Angular: `ControlValueAccessor`.                                                                                                                                                                          |
| Grupos com separador                          | input-otp, shadcn, HeroUI (`Group`, `Separator`)    | adapt    | `groups: number[]` (soma = `length`); a família desenha `group` e `separator`. Um `123-456` é como o SMS chega.                                                                                                                                                |
| Caixas unidas                                 | Chakra (`attached`), shadcn (estilo por omissão)    | adopt    | `attached`: as caixas de um grupo partilham a aresta, com canto só nas pontas.                                                                                                                                                                               |
| Variante de moldura                           | Chakra (`outline \| subtle \| flushed`), HeroUI, Mantine | adapt | `variant: outline \| subtle`, os dois passos que `text-field` já define. `plain` fica fora: um código nunca é uma célula. `flushed` fica fora: nenhuma outra família desenha só a base.                                                                    |
| Tamanho                                       | Chakra, Mantine, HeroUI                             | adopt    | `size: sm \| md \| lg`, do `field` primeiro, como todo o controlo.                                                                                                                                                                                           |
| Uma parada de foco, um `<label>`, um valor    | input-otp                                           | adopt    | O escopo. As caixas são `aria-hidden`; o `field` liga `label`, descrição e erro ao input.                                                                                                                                                                    |
| Teclado ←/→/Backspace/Delete/Home/End/Ctrl+A/Shift+← | input-otp (nativo), Ark (←/→/Backspace/Delete) | adopt | Tudo nativo do `textbox`. A família só normaliza a seleção: dentro do valor há sempre um carácter selecionado, para que digitar substitua em vez de ser recusado pelo `maxlength`.                                                                              |
| Estado por caixa                              | input-otp (`isActive`), Ark (`data-index`, `data-complete`) | adapt | `data-current` na caixa onde está o cursor ou a seleção, `data-index`, `:empty` para vazia; `data-complete` na raiz quando o valor tem `length` caracteres.                                                                                               |
| Elemento raiz substituível                    | Ark/Chakra (`asChild`), Mantine (polimórfico)       | adopt    | React: `render(rootProps)`. Angular: `[slOtpInput]` no elemento do consumidor. As caixas não são substituíveis: são pintura sobre um input e a sua geometria é o que o ponteiro mapeia.                                                                       |
| Defaults por aplicação                        | Mantine (theme), Angular Material (nenhum aqui)     | adopt    | `OtpInputDefaultsProvider` / `provideOtpInputDefaults`: `size`, `variant`, `attached`, `length`, `type`, `placeholder`.                                                                                                                                       |

## 3. Diferenciadores

| Capacidade                            | Fonte                                         | Decisão                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| WebOTP                                | plataforma (MDN); nenhuma implementação lida  | `webOtp`: quando `OTPCredential` existe, a família pede o código por `navigator.credentials.get`, aborta no `submit` do form e ao desmontar, e escreve o valor com razão `programmatic`. Opt-in, porque a chamada abre um pedido de permissão. Não verificável nesta máquina; dito no gate.                                        |
| Clique na caixa põe o cursor na caixa | nenhuma; input-otp deixa o clique ao input    | `pointerdown` na raiz mapeia o ponto à caixa por `elementsFromPoint`, foca o input e seleciona esse índice, limitado ao comprimento do valor. Em input-otp o texto invisível tem `letter-spacing: -.5em`, por isso o clique cai no início ou no fim.                                                                               |
| Três esquemas, três densidades, RTL   | a fundação                                    | Caixa quadrada na altura do controlo (`--slotted-control-height-*`), tipo do passo de texto, aresta do controlo; a fila de caixas é sempre LTR (`direction: ltr` na raiz), porque um código é um número e um número não espelha — o bidi mantém uma sequência de dígitos LTR num input RTL; a raiz fica onde a página a põe.                                                                                                                              |
| Cursor falso que pára em reduced motion | input-otp (pisca sempre)                    | O cursor da caixa corrente pisca no `--slotted-duration-loop` e fica fixo sob `prefers-reduced-motion`.                                                                                                                                                                                                                          |
| Dois bindings                         | —                                             | React `OtpInput` com `ref` no input; Angular `[slOtpInput]` + `input[slOtpInputControl]` com `ControlValueAccessor`, `exportAs` e `provideOtpInputDefaults`.                                                                                                                                                                       |

## 4. Gaps

| Situação                                  | Quem falha                              | Decisão                                                                                                                                                                                                                               |
| ----------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reenviar código com contagem              | todos                                   | Composição: um `button` e um texto ao lado, na página. A família não tem relógio. A página de referência mostra a composição.                                                                                                          |
| `form.reset()`                            | Ark, Mantine (N inputs sem form nativo) | Nativo: o input restaura `defaultValue`; React ouve `reset` no form para repintar as caixas, como `text-field` faz para o seu espelho.                                                                                                |
| Valor inicial mais longo que `length`     | todos                                   | Cortado a `length` e filtrado pelo tipo ao entrar. Um `defaultValue="12345678"` num campo de 6 mostra `123456`.                                                                                                                       |
| Colagem com espaços, hífens, `G-`         | input-otp (`pasteTransformer`)          | `transform` do consumidor primeiro; sem ele, o filtro por tipo descarta o que não é aceite e `onRejected` reporta-o.                                                                                                                  |
| Forced colors                             | input-otp (texto transparente reforçado) | O input recebe `forced-color-adjust: none` para continuar invisível; as caixas leem os tokens que o tema já remapeia.                                                                                                                  |
| Contentor a 240 px                        | input-otp (caixas de largura fixa)      | As caixas encolhem (`flex: 0 1 <altura>`, `min-inline-size: 0`) antes de a linha transbordar.                                                                                                                                         |
| Gestor de palavras-passe a marcar o campo | input-otp (`pushPasswordManagerStrategy`) | Não tratado: a família não mede badges de extensões. `autocomplete="one-time-code"` é o sinal que os gestores respeitam; um badge que aparece é sobreposto pela caixa da última posição e não impede a digitação.                    |
