# Split button and toggle — capability inventory

Two families, one session, one decision: each is a `button` with one more
semantic. `split-button` is a `button` beside a menu button, joined; `toggle`
is a `button` carrying `aria-pressed` outside a group. The inventory is taken
from the field before any code, as
`.claude/skills/component/references/capability.md` requires, and the delta
against what `button`, `button-group`, `menu` and `toggle-group` already ship
is named in §5.

Two names hide one capability. Radix's `Toggle`, Base UI's `Toggle`, Ark's
`Toggle`, React Aria's `ToggleButton`, Fluent's `ToggleButton` and shadcn's
`Toggle` are one control: a `button` whose `aria-pressed` the consumer may own.
Fluent's `SplitButton`, Atlassian's `SplitButton`, PrimeNG's `p-splitbutton`,
Kendo's `SplitButton`, Ant's `Dropdown.Button` and Carbon's `ComboButton` are
one control: a button and a menu button joined, each with its own name.

| Capability                                                                             | Who ships it                                                   | Verdict                  | Reason                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A native `button` with `aria-pressed` in both states                                    | Radix, Base UI, Ark, React Aria, Fluent, shadcn, APG           | adopt                    | `aria-pressed="true\|false"` always present, so the control is announced as a toggle rather than as a button that happens to be pressed — the rule `toggle-group`'s item already holds.                                                                                                                                                                                                                                             |
| `pressed` controlled and uncontrolled, with a change callback                           | Radix, Base UI, Ark, React Aria (`isSelected`), Fluent (`checked`) | adopt                | `pressed` / `defaultPressed` / `onPressedChange(pressed, request)`, reasons `pointer` and `keyboard` — the model `button`'s ToggleButton and `toggle-group` already declare, from `@slotted/core/state`.                                                                                                                                                                                                                              |
| The label does not change with the state                                                | APG, React Aria, Fluent                                        | adopt                    | Held by the family's own shape: `label` is a part and the state is an attribute beside it. The reference page shows "Wrap" staying "Wrap".                                                                                                                                                                                                                                                                                          |
| `disabled`                                                                              | every surveyed implementation                                  | adopt                    | The native attribute, so `:disabled` and the focus ring agree; `data-disabled` beside it for a group taken out with a `fieldset`.                                                                                                                                                                                                                                                                                                    |
| Substituting the element                                                                | Radix (`asChild`), Base UI (`render`, `nativeButton`), Ark (`asChild`), React Aria | adopt      | `render` in React; the directive on the consumer's `button` in Angular. | The state in the DOM for styling                                                        | Radix (`data-state`), Ark (`data-pressed`), React Aria (`data-selected`), Base UI | adopt     | `data-pressed`, the attribute the shared vocabulary names.                                                                                                                                                                                                                                                                                                                                                                          |
| A variant that is quiet until on, and one with an edge                                  | shadcn (`default`, `outline`), Fluent (`appearance`), `toggle-group` (`ghost`, `outline`) | adopt | `variant="outline\|ghost"`, default `outline`, the two `toggle-group` paints. | `size`                                                                                  | shadcn, Fluent, `toggle-group`                                 | adopt                    | `sm`, `md`, `lg`, from `--slotted-control-*`.                                                                                                                                                                                                                                                                                                                                                                                       |
| An icon beside or instead of the label                                                  | shadcn, Fluent, React Aria (children), `toggle-group`          | adopt                    | `icon` and `label` parts. | An indicator that changes with the state                                                | Ark (`Toggle.Indicator`), React Aria (render props)            | decline — composed       | The consumer selects `[data-pressed]` on the root and swaps what the `icon` part holds; two lines, and it reserves no width on an item that is off. `toggle-group` declined `selectionIndicator` for the same reason.                                                                                                                                                                                                                |
| An identity inside a group (`value`)                                                    | Base UI (`value`), React Aria (`id`)                           | defer to `toggle-group`  | The group owns its item and its value, so there is no fact for a standalone toggle to carry. `toggle-group` takes this family as its item when it is next opened; recorded in §5.                                                                                                                                                                                                                                                   |

## 4. Differentiators and gaps

| Kind            | Capability                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| differentiator  | Both halves of the split button are `button` unchanged — five tones, three variants, three sizes, three densities, three schemes, `loading` with the width held — and the menu is `menu` unchanged, with submenus, radio items, typeahead and `finalFocus`. Fluent re-declares the two as slots of a third component; Atlassian, Ant and MUI leave the join to the consumer or paint it ad hoc.       |
| differentiator  | `remember` is a declared option with a state model. MUI's example moves the label silently; Kendo leaves it to `onItemClick`. Here the choice is a radio group a reader hears as one, the primary reads from a value the consumer may own, and a product can persist it — GitHub's merge button, per repository.                                                                                    |
| differentiator  | `toggle` and `button`'s ToggleButton are two members with two meanings and one state model. No surveyed library says which of its two toggles is a mode and which is an action; shadcn ships both and calls them `Toggle` and `Button` with `data-state`.                                                                                                                                             |
| differentiator  | A standalone toggle inside `toolbar` is one control of the bar: the bar takes its tab stop, the arrows reach it, `Space` and `Enter` press it. No listener is written; the bar already handles every focusable control it holds.                                                                                                                                                                       |
| gap             | A menu button beside an action that is submitting. No surveyed implementation says what the second half does while the first is in flight; here `loading` on the root makes the trigger `aria-disabled` and keeps its name, and the reference page shows it.                                                                                                                                       |
| gap             | A split button whose action is long and translated. The primary's label wraps inside its own control and the trigger stays square; at 240 pixels the bar narrows before the page does, because the root states `min-inline-size: 0` as `button-group` does. Photographed at 240.                                                                                                                       |
| gap             | A toggle whose label is long and translated. The label clamps to one line with an ellipsis and keeps its string whole — `toggle-group`'s rule; the accessible name is unchanged.                                                                                                                                                                                                                      |
| gap             | A toggle that is on and unavailable. Both facts are kept: the ground says unavailable, the edge says on, in the two places the live state uses them. `toggle-group` records the same case and `high-contrast` proves it, where the ground is the page's own white.                                                                                                                                       |

## 5. What is already shipped, what the field ships, and the delta

- **`button`'s ToggleButton stays.** It is the action that persists and waits;
  `toggle` is the mode that switches. The two hold one state model and
  different paint, and the reference page of `toggle` says which to reach for.
- **`toggle-group`'s item is the picture `toggle` paints, and the two are one
  sheet of rules written twice until `toggle-group` is reopened.** The design
  doc of 2026-09-10 kept the item inside the group so the group is the value's
  only owner. That reasoning stands; a `toggle` that defers to an enclosing
  group's context is the Base UI shape and it is the reopen recorded in
  `docs/process/build-order.md` for `toggle-group`: its item becomes `toggle`, and the
  duplicated paint leaves. Not this session's — the file is another family's.
- **`menu` is held, not restated.** No part of it is re-exported; the menu
  part of the split button is a `Menu` whose trigger the family renders.
- **`button-group`'s join is restated for two children.** The root is the
  family's own element and `button-group`'s stylesheet keys on its own
  identifier, so the rules that make one shape of two controls are written
  here, citing the measurements `button-group` made. Cost: one seam decided in
  two places. A shared rule was considered and declined: an element carries
  one `data-ui`, and a nested `button-group` inside the root is an element the
  DOM does not need.
- **Two families and not one.** A split button is a group of two actions; a
  toggle is one control with a state. They share a session because the
  decision — what a `button` with one more semantic composes and what it owns —
  is one decision, taken once above.
