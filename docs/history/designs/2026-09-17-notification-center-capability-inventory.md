# Notification center — capability inventory

The persistent list of what happened to the reader while they were not
looking: read and unread, grouped, filtered, marked all at once, acted on,
and loaded a page at a time. One model behind three surfaces — the count on
the bell, the popover under it, and the page that shows everything. The
inventory is taken from the field before any code, as
`.claude/skills/component/references/capability.md` requires; the delta
against what `timeline`, `top-navigation`, `popover`, `badge` and
`result-state` already ship is named in §5.

## 2. Table stakes

| Capability                                                                    | Who ships it                                                       | Verdict                          | Reason                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Read and unread per item, with a mark                                         | every surveyed implementation                                      | adopt                            | `read` on the item; unread draws the accent dot, the semibold title and a tinted ground. It is a fact the consumer's store holds, so the family asks — `onReadChange({ keys, read, reason })` — and never flips it itself. `read` is a new word in the state vocabulary (`data-read`) and the capability list; the reason is in `specs/contract.schema.mjs`.                   |
| Mark all as read                                                              | Novu, Knock, GitHub, Linear (archive all)                          | adopt                            | The `mark-all` control in the header asks with every unread key at once and the reason `pointer` or `keyboard`; disabled when nothing is unread.                                                                                                                                                                                                                              |
| Mark one read or unread, from the item                                        | UI5 (`read`), GitHub (Read, Unread), Linear, Knock                 | adopt                            | The `read-toggle` control on every item, `--slotted-icon-check` / `--slotted-icon-dot`, named by `messages.markRead` / `markUnread`.                                                                                                                                                                                                                                          |
| Dismiss, archive or done                                                      | UI5 `showClose` + Delete, GitHub Done, Novu archive, Linear delete | adopt                            | `removable`: the `dismiss` control and the Delete key ask `onRemove(key, reason)`; the consumer's collection decides, as `tag` and `tabs` already do.                                                                                                                                                                                                                         |
| Views: all, unread, and the product's own                                     | Knock status filter, Novu tabs, GitHub Inbox/Saved/Done            | adopt                            | `view` / `defaultView` / `onViewChange` — the `current` capability — over `views`, a list of `{ value, label }` the consumer states. `all` and `unread` are built in and the family filters `unread` from the items it holds; any other view is the consumer's query and arrives as another `items`.                                                                              |
| A count on the bell                                                           | every surveyed implementation                                      | adopt — holds `top-navigation`   | `top-navigation`'s `notifications` control already draws the bell and the count. The family exposes the unread count through `onUnreadChange` and the reference page wires it.                                                                                                                                                                                              |
| The popover under the bell, and the page that shows everything                | Novu, Knock, MagicBell, GitHub                                      | adopt — holds `popover`, `page`  | The family is the content; `popover` opens it under the bell and `page` gives it a screen. `open`, placement and dismissal are the popover's. | Groups                                                                        | UI5 group items, GitHub (by date, by repository)                    | adapt                            | `groupBy: (item) => { key, label }` renders `group` sections with a `group-label` heading. | Incremental loading                                                           | UI5 `growing` + `load-more`, Knock and MagicBell pagination        | adopt                            | `growing="none" \| "button" \| "scroll"` with `onLoadMore` and `count`, the vocabulary `timeline` already holds; `loading` on the root.                                                                                                                                                                                                                                       |
| Live arrivals that do not reorder under the reader                            | Knock and Novu prepend live; `timeline`'s `fresh` holds them         | adapt                            | `arrivals="hold" \| "show"`. ## 3. Differentiators

| Capability                                                     | Reason                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Arrivals are held while the reader reads, by the family        | Novu and Knock prepend live and the list moves under the reader's pointer; `timeline` leaves the holding to the consumer. Here the family reads focus and scroll position and decides, with a switch to turn it off.                                              |
| One model, three surfaces, no adapter                          | The same `items` array feeds the bell's count, the popover and the page; nothing is fetched, nothing is a client SDK. A product that wants Novu's backend writes the adapter once and the family never knows.                                                     |
| Every request carries a reason and can be cancelled            | `onReadChange`, `onRemove`, `onOpen`, `onReveal`, `onLoadMore`, `onViewChange` — the vocabulary `docs/state-and-events.md` requires, where UI5 fires events after the fact.                                                                                        |
| Three schemes, three densities, right-to-left                  | The unread dot is `--slotted-tone-accent-solid` on the accent surface pair the foundation measured; the item's ground tints from the tone's text at `--slotted-highlight-tint-opacity`; every inset is logical, and the dot sits at the inline start under RTL.  |

## 4. Gaps

| Situation                                                   | Answer                                                                                                                                                                                                              |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A notification arrives while the reader is on an article     | Held behind `fresh`; PageUp from the first article reaches the control, and pressing it reveals and moves focus to the first new article.                                                                             |
| A title of forty words, a body of two hundred                | Clamped at two and three lines; the whole text stays in the DOM, and the item opens the thing.                                                                                                                       |
| Three hundred unread                                         | The count is a `badge` with `max`; `mark-all` asks with three hundred keys in one request and the consumer batches it.                                                                                               |
| Every item read                                              | The `unread` view shows the empty page with `messages.caughtUp`; `mark-all` is disabled.                                                                                                                             |
| A removal that fails on the server                           | The consumer refuses in `onRemove` or restores the item; the family removed nothing itself.                                                                                                                          |
| The same key twice                                           | The last one wins in the family's map and development warns.                                                                                                                                                         |

## 5. Delta against what is already shipped

| Already shipped                      | This family                                                                                                                                                         |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `timeline mode="feed"`               | The Feed keyboard and the timestamp formatting are taken from `@slotted/core/timeline`; the paint is not, because a notification is a row with a dot, not an event on a rail. |
| `top-navigation` notifications       | The bell and its count; the family gives the count.                                                                                                                 |
| `popover`, `page`                    | The hosts.                                                                                                                                                          |
| `tabs`                               | The views strip, list only; the feed is the one panel.                                                                                                              |
| `badge`, `button`, `skeleton`, `result-state`, `avatar`, `menu` | Composed inside: the counts, the controls, the wait, the empty page, the visual, the per-item menu.                                                          |
