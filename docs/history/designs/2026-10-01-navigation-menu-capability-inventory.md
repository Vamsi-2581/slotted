# Inventário de capacidades — `navigation-menu`

Família nova. `docs/component-features.md` não tem secção para ela; o âmbito
escrito em `docs/process/build-order.md` deriva deste inventário. Lido em 1 de
outubro de 2026. Dossiê de medidas: `2026-10-01-navigation-menu-reui-dossier.md`.

Termo: **painel de navegação** — a região de destinos que um botão de secção
mostra e esconde por baixo (ou ao lado) da barra, com links, grupos e rodapé.

## 2. Table stakes

| Capacidade                                                  | Quem envia                         | Veredicto | Razão                                                                                                                                                                       |
| ----------------------------------------------------------- | ---------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Item aberto controlável (`value`, pedido com razão)         | Radix, Base UI, Ark                | adapt     | `value`/`defaultValue`/`onValueChange(value, request)`, razões `pointer`, `keyboard`, `escape`, `outsidePress`, `blur`, `select`, `programmatic`.                           |
| Abrir por hover com atraso e fechar com atraso              | Radix, Base UI, Ark, ReUI          | adopt     | `openDelay` 200 e `closeDelay` 300 ms (Radix e Ark); ponteiro `touch` não abre por hover.                                                                                    |
| Troca imediata entre secções com o painel aberto            | Radix (`skipDelayDuration`), Base UI | adopt   | Com uma secção aberta, o hover noutro gatilho troca sem atraso.                                                                                                             |
| Abrir e fechar por clique                                   | todos                              | adopt     | `button` nativo; nada importante depende de hover (`component-features.md` §2.7).                                                                                            |
| Viewport partilhado que mede e anima o tamanho              | Radix, Base UI, ReUI               | adopt     | Parte `viewport`; o script publica `--slotted-navigation-menu-viewport-*`; a superfície transita largura, altura e posição.                                                  |
| Direção de movimento entre secções                          | Radix (`data-motion`), Base UI (`data-activation-direction`) | adopt | `data-motion` `from-start`/`from-end`/`to-start`/`to-end` no `content`, em termos lógicos.                                                                                |
| Marca que segue o gatilho ativo                             | Radix (`Indicator`), Base UI (`Arrow`), ReUI | adapt | Parte `arrow` na aresta do viewport, centrada no gatilho aberto, que desliza entre gatilhos.                                                                               |
| Chevron no gatilho que roda ao abrir                        | Base UI (`Icon`), ReUI             | adopt     | Parte `indicator`, Glyph `chevron-down`, meia volta, como `top-navigation`.                                                                                                  |
| Link no topo da lista, sem painel                           | todos                              | adopt     | `link` direto em `item`, com a geometria do gatilho.                                                                                                                         |
| Link corrente                                               | Base UI (`active`), Ark (`current`), APG (`aria-current`) | adopt | `current` no link; `aria-current="page"`; o gatilho cuja secção contém o corrente leva `data-current`.                                                         |
| Fechar ao escolher um link                                  | Base UI (opção), Ark (omissão)     | adopt     | `closeOnSelect` verdadeiro por omissão, razão `select`: numa aplicação de página única a rota muda e o painel não.                                                          |
| Escape fecha e devolve o foco ao gatilho                    | APG, Radix, Base UI, Ark           | adopt     | `dismissable-layer`, ramo no gatilho.                                                                                                                                         |
| Setas, `Home`, `End`                                        | APG (opcional), Radix, Ark         | adopt     | Suplementares à ordem de Tab; sem tabindex rotativo (§ desenho).                                                                                                             |
| Orientação vertical                                         | Radix, Ark                         | adopt     | `orientation="vertical"`: o viewport abre no fim em linha, alinhado ao gatilho.                                                                                              |
| Submenu / segundo nível                                     | Radix (`Sub`), Base UI (aninhado)  | adapt     | A família aninha-se: uma raiz dentro de um `content` é `div`, sem landmark, vertical, com viewport em linha.                                                                  |
| Elemento substituível (router link)                         | Radix (`asChild`), Base UI (`render`) | adopt  | `render` em React; diretivas sobre o elemento do consumidor em Angular.                                                                                                      |
| Conteúdo montado só quando aberto / forçado                 | Radix (`forceMount`), Ark (`lazyMount`) | adapt | O conteúdo fica no DOM e escondido (`hidden`), porque a ordem de Tab do APG o pede e um motor de busca lê os destinos; custo no desenho.                                    |
| Links ricos (ícone, título, descrição) em grelha            | ReUI c-2, c-4, navbar-12; Radix demo | adopt   | Partes `icon`, `label`, `description` no `link`; `links` (`ul`) com `columns` 1–3.                                                                                          |
| Grupo com título                                            | navbar-12 (duas colunas por secção), Radix demo | adopt | `group` e `group-label`.                                                                                                                                       |
| Rodapé de painel (chamada à ação)                           | ReUI c-4                           | adopt     | Parte `footer`, régua superior; o botão é do consumidor (`button`).                                                                                                          |
| Cartão de destaque (imagem, gradiente)                      | Radix demo                         | decline   | Composto por `card` dentro de `content`: `<Card render={<a href="/">…</a>}>` numa célula de `links` com `grid-row: span 3`.                                                 |
| Backdrop                                                    | Base UI                            | decline   | Um painel de navegação não é modal; quem o quer escreve `[data-ui='navigation-menu']:has([data-part='viewport'][data-open])::after`. A família não escurece a página.        |

## 3. Differentiators

| Capacidade                                    | Razão                                                                                                                                                                                                                            |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ordem do DOM do APG com viewport partilhado   | Radix e Base UI portam o conteúdo para o viewport e reconstroem a ordem de Tab com sentinelas. Aqui o `content` fica no seu `li`, depois do gatilho; só a superfície (`viewport`) é partilhada e o conteúdo é posicionado sobre ela. |
| Painel que reflui pela própria largura        | `content` é contentor de consulta com largura definida (`columns × column-size`, limitada ao espaço disponível); `links` cai para uma coluna abaixo de 480 px sem consulta de viewport.                                         |
| Três esquemas, três densidades, rtl           | Altura, inset e tipo do gatilho e do link lidos da escala de controlo; `data-motion` lógico; o `arrow` e o viewport medidos do início em linha.                                                                                     |
| Duas ligações de primeira classe              | Angular com `model()` para `value`, `provideNavigationMenuDefaults()` para atrasos, tamanho e mensagens.                                                                                                                         |
| Alinhamento do texto do painel com o gatilho  | O inset do link é o padding do controlo menos a borda e o inset do viewport, para o primeiro texto do painel começar na coluna do rótulo do gatilho, regra de `menu`.                                                             |

## 4. Gaps

| Caso                                                | Resposta                                                                                                                                                         |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Painel mais largo do que o espaço à direita         | O script desloca o viewport para o início até caber e escreve a posição do `arrow` relativa ao gatilho, que continua a apontar para ele.                          |
| Página estreita (375 px)                            | O painel toma a largura disponível menos o gutter e `links` cai para uma coluna.                                                                                  |
| Título e descrição longos ou traduzidos             | `label` quebra em linhas; `description` limita-se a duas linhas por `line-clamp`, com o texto inteiro no DOM.                                                   |
| Hover acidental ao atravessar a barra               | `openDelay`; a troca sem atraso só existe com uma secção já aberta.                                                                                             |
| Ponteiro a sair na diagonal para o painel           | `closeDelay` e o painel colado ao gatilho por um gap que pertence à superfície; o ponteiro não atravessa página vazia.                                            |
| Ecrã tátil                                          | Hover ignorado para `pointerType` `touch`; o toque é um clique.                                                                                                  |
| Secção desativada                                   | `disabled` nativo no gatilho; link com `aria-disabled` e ativação recusada.                                                                                       |
| Raiz recortada por `overflow: hidden` do consumidor | Custo escrito no desenho: o viewport fica dentro da raiz.                                                                                                         |
