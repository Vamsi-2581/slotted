# Plano — site de documentação oficial

Desenho: `docs/history/designs/2026-10-01-docs-site-design.md`. Checkpoint: `.claude/progress/docs-site.md`.

## Fatia 1 — fundação

1. **Registro.** Desenho, plano, linha no índice de designs, `apps/` em `docs/decisions/0002-repository-layout.md` passa a incluir `apps/docs`.
2. **Scaffold.** `apps/docs` com Astro 7, MDX, React, aliases de código-fonte, layout base e uma página de fundamento. Aceite: `pnpm --filter @slotted/docs build` gera `dist/foundations/introduction/index.html`.
3. **Runtime React e `<Example>`.** `examples/react/field/basic.tsx`, runtime React (`render` + `mount`), componente `Example.astro` com o preview acima e o código abaixo, num `CodeBlock` de `@slotted/react` com tokens Shiki. Aceite: o HTML gerado contém `data-ui="field"` dentro do preview e tokens com escopo no `code-block`.

## Fatia 2 — Angular e navegação

4. **Runtime Angular.** `@analogjs/vite-plugin-angular` no Vite do Astro; `render` por `@angular/platform-server`; `mount` por `createComponent`. Aceite: `examples/angular/field/basic.ts` gera `data-ui="field"` no HTML do build. Falha → plano B do desenho.
5. **Modelo de conteúdo e rotas.** Coleções `components` e `foundations`; rotas `/<framework>/`, `/<framework>/components/<family>`, `/foundations/<slug>`; navegação lateral gerada das coleções.
6. **Interface do site.** Cabeçalho com seletor de framework, esquema (light, dark, high-contrast) e densidade, montado com `@slotted/react`; barra de controles do preview.

## Fatia 3 — dados derivados e verificações

7. **API.** `tools/docs-extract` (ou módulo em `apps/docs/scripts`) gera JSON de API por framework; componente `ApiTable`.
8. **Contrato e tokens.** Seções de teclado e acessibilidade de `contract.json`; tabela de tokens de `tokens.json`.
9. **Verificações.** Paridade de catálogo, paridade de DOM (sobre `render` dos dois runtimes), idioma, links; script `verify` do pacote ligado ao turbo.

## Fatia 4 — primeiras páginas públicas

10. Início por framework; fundamentos: installation, theming, tokens, cascade layers.
11. Famílias piloto completas: `button`, `field`, `combobox`.
12. Pagefind + command palette; rotas `.md` e `llms.txt`; cenário Playwright de montagem; `pnpm check:affected`.

## Depois do piloto

Plano separado para migrar as demais famílias a partir de `*.docs.ts`, com reescrita em inglês.
