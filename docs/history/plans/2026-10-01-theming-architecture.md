# Arquitetura de tematização — plano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um tema passa a ser um módulo `defineTheme` tipado que transporta sementes de cor, uma receita que deriva os tokens de cor em CSS, tokens nos três níveis, fontes e regras CSS com escopo; uma semente arbitrária definida em runtime recolore os três esquemas sem build e sem perder os rácios de contraste.

**Architecture:** `@slotted/tokens` passa a `@slotted/theme` (TypeScript, Vite + tsc, como `@slotted/core`) e `@slotted/theme-default` passa a `@slotted/themes`. A receita é dado: cada token de cor é uma derivação OKLCH de uma semente, emitida como `oklch(from var(--slotted-seed-*) …)` e avaliada em JS com a mesma aritmética. Um teto/piso de luminosidade dependente de matiz e croma (`Bound`) garante os rácios para qualquer semente. Os blocos de esquema passam a `@scope` com `[data-slotted-seeds]`; as regras de tema vão para a subcamada `slotted.theme-rules` dentro de `@scope` do tema.

**Tech Stack:** TypeScript 6.0.3, Vite 8.2.2 (lib mode), Vitest 4.1.11, `node --test`, lightningcss 1.33.0 (já no lockfile por `vite`), React 19, Angular 22 (signals), Chrome headless via `tools/harness/shoot.mjs`.

**Spec:** `docs/history/designs/2026-10-01-theming-architecture-design.md`. `§<n>` aponta para esse documento.

## Review Focus

1. Uma semente escrita à mão em runtime com um valor que não é cor (`setProperty('--slotted-seed-accent', 'banana')`): `@property` com `syntax: '<color>'` torna o valor inválido e o token computa `gray`; `seedStyle` recusa-o antes. Teste na Tarefa 9 (`seedStyle` lança).
2. Um nome de tema com aspas ou espaços quebraria todos os seletores emitidos. Teste na Tarefa 5 (`defineTheme` recusa `'my theme'` e `'a"b'`).
3. Regras de tema com `@import`, `@layer` ou `@scope` próprios: o compilador já envolve as regras em camada e escopo. Teste na Tarefa 6 (`processRules` lança com mensagem que nomeia a at-rule).
4. `applyTheme` chamado duas vezes com o mesmo nome e conteúdos diferentes: a folha é substituída, não duplicada. Teste na Tarefa 9.
5. Semente acromática (cinzento, croma 0, matiz sem significado): o browser e o avaliador têm de concordar. Teste na Tarefa 11 (o cenário de paridade inclui sementes de croma 0).

```ts
import { describe, expect, it } from 'vitest';

import { contrast, deltaE, parseSeed, relativeLuminance, toHex } from './color';

describe('parseSeed', () => {
  it('reads six- and three-digit hex in either case', () => {
    expect(toHex(parseSeed('#1D4ED8')!)).toBe('#1d4ed8');
    expect(toHex(parseSeed('#fff')!)).toBe('#ffffff');
  });

  it('reads oklch with a number or a percentage lightness and an optional deg unit', () => {
    const number = parseSeed('oklch(0.5 0.2 264)')!;
    const percent = parseSeed('oklch(50% 0.2 264deg)')!;
    expect(number).toEqual({ l: 0.5, c: 0.2, h: 264 });
    expect(percent).toEqual(number);
  });

  it('refuses anything else', () => {
    for (const text of ['red', 'rgb(0 0 0)', '#12345', 'oklch(1.2 0.1 0)', 'oklch(0.5 -0.1 0)', '']) {
      expect(parseSeed(text), text).toBeNull();
    }
  });
});

describe('contrast', () => {
  it('is 21 between black and white', () => {
    expect(contrast(parseSeed('#000')!, parseSeed('#fff')!)).toBeCloseTo(21, 5);
  });

  it('matches the WCAG ratio of an sRGB pair', () => {
    expect(contrast(parseSeed('#1d4ed8')!, parseSeed('#ffffff')!)).toBeCloseTo(6.7, 1);
  });

  it('takes the lower of the clipped and unclipped ratios for a colour outside sRGB', () => {
    const outside = { l: 0.6, c: 0.35, h: 150 };
    const { raw, clipped } = relativeLuminance(outside);
    expect(raw).not.toBeCloseTo(clipped, 3);

    expect(contrast(outside, white)).toBeCloseTo(Math.min(ratio(Math.max(0, raw)), ratio(clipped)), 6);
```

`packages/theme/src/format.ts`:

```ts
/**
 * A number as CSS reads it: five decimals at most, no exponent, no trailing
 * zeros. The evaluator rounds coefficients to the same five decimals, so the
 * browser and the evaluator compute with the same constants.
 */
export function fmt(value: number): string {
  const rounded = Number(value.toFixed(5));
  return Object.is(rounded, -0) ? '0' : String(rounded);
}
```

`packages/theme/src/color.ts`:

```ts
/**
 * Colour arithmetic for themes: OKLCH in, relative luminance and sRGB out. The
 * matrices are Björn Ottosson's OKLab reference. A theme carries its seeds in
 * OKLCH because the recipe derives every token by moving lightness and chroma
 * along a fixed hue, which is what `oklch(from …)` computes in the browser.
 */
export interface Oklch {
  readonly l: number;
  readonly c: number;
  readonly h: number;
}

const clamp = (value: number, min: number, max: number) => Math.min(max, Math.max(min, value));

function toLinear(channel: number): number {
  return channel <= 0.04045 ? channel / 12.92 : ((channel + 0.055) / 1.055) ** 2.4;
}

function toGamma(value: number): number {
  return value <= 0.0031308 ? value * 12.92 : 1.055 * value ** (1 / 2.4) - 0.055;
}

/** sRGB channels in 0–1 to OKLCH. A chroma under 1e-4 has no hue; it reads as 0. */
export function fromSrgb(r: number, g: number, b: number): Oklch {
  const [lr, lg, lb] = [toLinear(r), toLinear(g), toLinear(b)];
  const l = Math.cbrt(0.4122214708 * lr + 0.5363325363 * lg + 0.0514459929 * lb);
  const m = Math.cbrt(0.2119034982 * lr + 0.6806995451 * lg + 0.1073969566 * lb);
  const s = Math.cbrt(0.0883024619 * lr + 0.2817188376 * lg + 0.6299787005 * lb);
  const L = 0.2104542553 * l + 0.793617785 * m - 0.0040720468 * s;
  const A = 1.9779984951 * l - 2.428592205 * m + 0.4505937099 * s;
  const B = 0.0259040371 * l + 0.7827717662 * m - 0.808675766 * s;
  const C = Math.hypot(A, B);
  const H = C < 1e-4 ? 0 : ((((Math.atan2(B, A) * 180) / Math.PI) % 360) + 360) % 360;
  return { l: L, c: C, h: H };
}

/** Linear-light sRGB, unclipped: a colour outside sRGB has a channel below 0 or above 1. */
export function toLinearSrgb({ l, c, h }: Oklch): [number, number, number] {
  const radians = (h * Math.PI) / 180;
  const a = c * Math.cos(radians);
  const b = c * Math.sin(radians);
  const l3 = (l + 0.3963377774 * a + 0.2158037573 * b) ** 3;
  const m3 = (l - 0.1055613458 * a - 0.0638541728 * b) ** 3;
  const s3 = (l - 0.0894841775 * a - 1.291485548 * b) ** 3;
  return [
    4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3,
    -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3,
    -0.0041960863 * l3 - 0.7034186147 * m3 + 1.707614701 * s3,
  ];
}

const HEX = /^#([\da-f]{3}|[\da-f]{6})$/i;
const OKLCH = /^oklch\(\s*(-?[\d.]+)(%?)\s+(-?[\d.]+)\s+(-?[\d.]+)(?:deg)?\s*\)$/i;

/** A seed in one of the two notations a theme accepts, or `null`. */
export function parseSeed(text: string): Oklch | null {
  const value = text.trim();
  const hex = HEX.exec(value);
  if (hex) {
    const body = hex[1]!;
    const digits = body.length === 3 ? [...body].map((digit) => digit + digit).join('') : body;
    const [r, g, b] = [0, 2, 4].map(
      (at) => Number.parseInt(digits.slice(at, at + 2), 16) / 255,
    ) as [number, number, number];
    return fromSrgb(r, g, b);
  }
  const oklch = OKLCH.exec(value);
  if (!oklch) return null;
  const l = Number(oklch[1]) / (oklch[2] === '%' ? 100 : 1);
  const c = Number(oklch[3]);
  const h = Number(oklch[4]);
  if (![l, c, h].every(Number.isFinite) || l < 0 || l > 1 || c < 0) return null;
  return { l, c, h: ((h % 360) + 360) % 360 };
}

export interface Luminance {
  /** Of the colour as computed, which a wide-gamut screen shows. Never below 0. */
  readonly raw: number;
  /** Of the colour clipped per channel to sRGB, which an sRGB screen shows. */
  readonly clipped: number;
}

export function relativeLuminance(color: Oklch): Luminance {
  const linear = toLinearSrgb(color);
  const y = ([r, g, b]: readonly number[]) => 0.2126 * r! + 0.7152 * g! + 0.0722 * b!;
  return {
    raw: Math.max(0, y(linear)),
    clipped: y(linear.map((value) => clamp(value, 0, 1))),
  };
}

function ratio(first: number, second: number): number {
  return (Math.max(first, second) + 0.05) / (Math.min(first, second) + 0.05);
}

/** The WCAG ratio a reader gets on either kind of screen: the lower of the two. */
export function contrast(first: Oklch, second: Oklch): number {
  const a = relativeLuminance(first);
  const b = relativeLuminance(second);
  return Math.min(ratio(a.raw, b.raw), ratio(a.clipped, b.clipped));
}

/** Six-digit hex of the colour clipped to sRGB. */
export function toHex(color: Oklch): string {
  return `#${toLinearSrgb(color)
    .map((value) =>
      Math.round(clamp(toGamma(clamp(value, 0, 1)), 0, 1) * 255)
        .toString(16)
        .padStart(2, '0'),
    )
    .join('')}`;
}

/** Euclidean distance in OKLab. */
export function deltaE(first: Oklch, second: Oklch): number {
  const lab = ({ l, c, h }: Oklch) => [
    l,
    c * Math.cos((h * Math.PI) / 180),
    c * Math.sin((h * Math.PI) / 180),
  ];
  const [p, q] = [lab(first), lab(second)];
  return Math.hypot(p[0]! - q[0]!, p[1]! - q[1]!, p[2]! - q[2]!);
}
```

```ts
import { relativeLuminance } from './color';
import type { Oklch } from './color';
import { fmt } from './format';

/**
 * A lightness limit that holds a contrast ratio for every hue and chroma.
 *
 * The relative luminance of an OKLCH colour depends on its hue and chroma as
 * well as on `l`: white text holds 4.5:1 up to l 0.568 at chroma 0, and the
 * limit moves by about ±0.13 × chroma with the hue. A bound is a least-squares
 * fit of the exact limit over chroma 0–`maxChroma` and every hue, moved by the
 * fit's largest error toward the safe side, so it never admits a colour the
 * exact limit refuses. `l + c·(T1 + c·(T2 + c·T3))`, each `Tp` a fourth-order
 * Fourier series in the hue.
 */
export interface Bound {
  readonly side: 'ceiling' | 'floor';
  readonly l: number;
  readonly k: readonly number[];
}

export const BOUND_POWERS = 3;
export const BOUND_HARMONICS = 4;
const TERMS = 1 + 2 * BOUND_HARMONICS;

function basis(h: number): number[] {
  const radians = (h * Math.PI) / 180;
  const values = [1];
  for (let n = 1; n <= BOUND_HARMONICS; n += 1) {
    values.push(Math.cos(n * radians), Math.sin(n * radians));
  }
  return values;
}

export function boundValue(bound: Bound, c: number, h: number): number {
  const trig = basis(h);
  let total = 0;
  for (let power = BOUND_POWERS; power >= 1; power -= 1) {
    let term = 0;
    for (let j = 0; j < TERMS; j += 1) term += (bound.k[(power - 1) * TERMS + j] ?? 0) * trig[j]!;
    total = c * (term + total);
  }
  return bound.l + total;
}

export function applyBounds(color: Oklch, bounds: readonly Bound[] = []): Oklch {
  let { l } = color;
  for (const bound of bounds) {
    const limit = boundValue(bound, color.c, color.h);
    l = bound.side === 'ceiling' ? Math.min(l, limit) : Math.max(l, limit);
  }
  return { l, c: color.c, h: color.h };
}

function termCss(bound: Bound, power: number): string {
  const k = (j: number) => fmt(bound.k[(power - 1) * TERMS + j] ?? 0);
  const parts = [k(0)];
  for (let n = 1; n <= BOUND_HARMONICS; n += 1) {
    parts.push(`${k(2 * n - 1)} * cos(calc(h * ${n}deg))`, `${k(2 * n)} * sin(calc(h * ${n}deg))`);
  }
  return `(${parts.join(' + ')})`;
}

/** The limit as a `calc()` over the `c` and `h` channel keywords of a relative colour. */
export function boundCss(bound: Bound): string {
  let inner = `c * ${termCss(bound, BOUND_POWERS)}`;
  for (let power = BOUND_POWERS - 1; power >= 1; power -= 1) {
    inner = `c * (${termCss(bound, power)} + ${inner})`;
  }
  return `calc(${fmt(bound.l)} + ${inner})`;
}

/** The exact limit at one hue and chroma, by bisection on lightness. */
function exactLimit(h: number, c: number, target: number, side: Bound['side']): number {
  let low = 0;
  let high = 1;
  for (let step = 0; step < 40; step += 1) {
    const middle = (low + high) / 2;
    const { raw, clipped } = relativeLuminance({ l: middle, c, h });
    if (side === 'ceiling') {
      if (Math.max(raw, clipped) <= target) low = middle;
      else high = middle;
    } else if (Math.min(raw, clipped) >= target) high = middle;
    else low = middle;
  }
  return side === 'ceiling' ? low : high;
}

function features(c: number, h: number): number[] {
  const trig = basis(h);
  const row: number[] = [];
  for (let power = 1; power <= BOUND_POWERS; power += 1) {
    for (const value of trig) row.push(c ** power * value);
  }
  return row;
}

function leastSquares(rows: number[][], targets: number[]): number[] {
  const size = rows[0]!.length;
  const a = Array.from({ length: size }, () => Array<number>(size).fill(0));
  const b = Array<number>(size).fill(0);
  rows.forEach((row, index) => {
    for (let i = 0; i < size; i += 1) {
      b[i]! += row[i]! * targets[index]!;
      for (let j = 0; j < size; j += 1) a[i]![j]! += row[i]! * row[j]!;
    }
  });
  for (let i = 0; i < size; i += 1) {
    let pivot = i;
    for (let r = i + 1; r < size; r += 1) if (Math.abs(a[r]![i]!) > Math.abs(a[pivot]![i]!)) pivot = r;
    [a[i], a[pivot]] = [a[pivot]!, a[i]!];
    [b[i], b[pivot]] = [b[pivot]!, b[i]!];
    for (let r = 0; r < size; r += 1) {
      if (r === i) continue;
      const factor = a[r]![i]! / a[i]![i]!;
      for (let col = i; col < size; col += 1) a[r]![col]! -= factor * a[i]![col]!;
      b[r]! -= factor * b[i]!;
    }
  }
  return b.map((value, i) => value / a[i]![i]!);
}

/**
 * The bound for a target relative luminance: a ceiling keeps the colour at or
 * under it, a floor at or over it. Coefficients are rounded before the error
 * is measured, so the shift covers the rounding as well as the fit.
 */
export function fitBound(target: number, side: Bound['side'], maxChroma = 0.25): Bound {
  const origin = exactLimit(0, 0, target, side);
  const rows: number[][] = [];
  const offsets: number[] = [];
  for (let c = 0; c <= maxChroma + 1e-9; c += 0.01) {
    for (let h = 0; h < 360; h += 3) {
      rows.push(features(c, h));
      offsets.push(exactLimit(h, c, target, side) - origin);
    }
  }
  const k = leastSquares(rows, offsets).map((value) => Number(value.toFixed(5)));
  let worst = 0;
  rows.forEach((row, index) => {
    const predicted = row.reduce((sum, value, j) => sum + value * k[j]!, 0);
    const error = side === 'ceiling' ? predicted - offsets[index]! : offsets[index]! - predicted;
    worst = Math.max(worst, error);
  });
  const l =
    side === 'ceiling'
      ? Math.floor((origin - worst - 0.001) * 1e4) / 1e4
      : Math.ceil((origin + worst + 0.001) * 1e4) / 1e4;
  return { side, l, k };
}
```

```ts
import { applyBounds, boundCss, type Bound } from './bound';
import type { Oklch } from './color';
import { fmt } from './format';

export const SEED_NAMES = ['accent', 'neutral', 'success', 'warning', 'danger'] as const;
export type SeedName = (typeof SEED_NAMES)[number];

export const SCHEMES = ['light', 'dark', 'high-contrast'] as const;
export type Scheme = (typeof SCHEMES)[number];

/** A colour taken from a seed: fixed or offset lightness, scaled chroma, shifted hue. */
export interface SeedDerivation {
  readonly seed: SeedName;
  readonly l: number | { readonly offset: number; readonly min?: number; readonly max?: number };
  readonly c: { readonly scale: number; readonly max: number };
  readonly h?: number;
  readonly bounds?: readonly Bound[];
}

/** A colour moved `share` toward white, or toward black when its lightness is above 0.9. */
export interface MixDerivation {
  readonly mix: string;
  readonly share: number;
  readonly bounds?: readonly Bound[];
}

export interface AliasDerivation {
  readonly alias: string;
}

export type Derivation = SeedDerivation | MixDerivation | AliasDerivation;

/** Per scheme, the derivation of every colour token the recipe owns. */
export type Recipe = Readonly<Record<Scheme, Readonly<Record<string, Derivation>>>>;

const clamp = (value: number, min: number, max: number) => Math.min(max, Math.max(min, value));
const hue = (value: number) => ((value % 360) + 360) % 360;

/**
 * Every token of one scheme, computed with the arithmetic `derivationCss`
 * writes: the browser's `oklch(from …)` and `color-mix(in oklch, …)` on the
 * same constants.
 */
export function evaluateRecipe(
  recipe: Recipe,
  seeds: Readonly<Record<SeedName, Oklch>>,
  scheme: Scheme,
): Record<string, Oklch> {
  const rules = recipe[scheme];
  const values: Record<string, Oklch> = {};

  const visit = (name: string, path: readonly string[]): Oklch => {
    const known = values[name];
    if (known) return known;
    if (path.includes(name)) throw new Error(`Recipe cycle at ${[...path, name].join(' → ')}`);
    const rule = rules[name];
    if (!rule) throw new Error(`${scheme}: the recipe has no rule for ${name}`);
    const next = [...path, name];

    let value: Oklch;
    if ('alias' in rule) {
      value = visit(rule.alias, next);
    } else if ('mix' in rule) {
      const base = visit(rule.mix, next);
      const white = clamp((0.9 - base.l) * 1_000_000, 0, 1);
      value = applyBounds(
        {
          l: base.l * (1 - rule.share) + white * rule.share,
          c: base.c * (1 - rule.share),
          h: base.h,
        },
        rule.bounds,
      );
    } else {
      const seed = seeds[rule.seed];
      const l =
        typeof rule.l === 'number'
          ? rule.l
          : clamp(seed.l + rule.l.offset, rule.l.min ?? 0, rule.l.max ?? 1);
      value = applyBounds(
        { l, c: Math.min(seed.c * rule.c.scale, rule.c.max), h: hue(seed.h + (rule.h ?? 0)) },
        rule.bounds,
      );
    }
    values[name] = value;
    return value;
  };

  for (const name of Object.keys(rules)) visit(name, []);
  return values;
}

/** The CSS value of one derivation. */
export function derivationCss(rule: Derivation): string {
  if ('alias' in rule) return `var(${rule.alias})`;

  let color: string;
  if ('mix' in rule) {
    color =
      `color-mix(in oklch, var(${rule.mix}), oklch(from var(${rule.mix}) ` +
      `clamp(0, calc((0.9 - l) * 1000000), 1) 0 none) ${fmt(rule.share * 100)}%)`;
  } else {
    const l =
      typeof rule.l === 'number'
        ? fmt(rule.l)
        : `clamp(${fmt(rule.l.min ?? 0)}, calc(l + ${fmt(rule.l.offset)}), ${fmt(rule.l.max ?? 1)})`;
    const c = `min(calc(c * ${fmt(rule.c.scale)}), ${fmt(rule.c.max)})`;
    const h = rule.h ? `calc(h + ${fmt(rule.h)})` : 'h';
    color = `oklch(from var(--slotted-seed-${rule.seed}) ${l} ${c} ${h})`;
  }
  for (const bound of rule.bounds ?? []) {
    color = `oklch(from ${color} ${bound.side === 'ceiling' ? 'min' : 'max'}(l, ${boundCss(bound)}) c h)`;
  }
  return color;
}
```

```ts
import { contrast, type Oklch } from './color';
import type { Scheme } from './recipe';

/** The text ratio each scheme promises. `high-contrast` earns its name at AAA. */
export const CONTRAST_REQUIREMENT: Readonly<Record<Scheme, number>> = {
  light: 4.5,
  dark: 4.5,
  'high-contrast': 7,
};

const NON_TEXT = 3;
const CONTROL_EDGE = 1.5;
const HIGHLIGHT_STEP = 0.02;
const SURFACES = ['--slotted-surface', '--slotted-surface-raised', '--slotted-surface-sunken'];
const TONES = ['accent', 'secondary', 'success', 'warning', 'danger'];

/**
 * The ratios of `theme-conformance` over evaluated colours, as messages. A
 * recipe passes when every seed of `seedGrid()` leaves this list empty.
 */
export function checkScheme(values: Readonly<Record<string, Oklch>>, scheme: Scheme): string[] {
  const failures: string[] = [];
  const text = CONTRAST_REQUIREMENT[scheme];
  const pair = (fore: string, ground: string, floor: number) => {
    const ratio = contrast(values[fore]!, values[ground]!);
    if (ratio < floor) failures.push(`${fore} on ${ground} is ${ratio.toFixed(2)}:1, below ${floor}:1`);
  };

  for (const surface of SURFACES) {
    pair('--slotted-text', surface, text);
    pair('--slotted-text-muted', surface, text);
    pair('--slotted-border-strong', surface, NON_TEXT);
    pair('--slotted-control-border-color', surface, CONTROL_EDGE);
    pair('--slotted-focus-ring-color', surface, NON_TEXT);
    for (const tone of TONES) pair(`--slotted-tone-${tone}-text`, surface, text);
  }
  for (const surface of ['--slotted-surface', '--slotted-surface-raised']) {
    const ground = values[surface]!.l;
    const hover = Math.abs(values['--slotted-tone-secondary-subtle-hover']!.l - ground);
    const active = Math.abs(values['--slotted-tone-secondary-subtle-active']!.l - ground);
    if (hover < HIGHLIGHT_STEP) failures.push(`the neutral highlight is ${hover.toFixed(3)} from ${surface}`);
    if (active <= hover) failures.push(`the pressed highlight is not beyond the hover on ${surface}`);
  }
  pair('--slotted-text-inverse', '--slotted-surface-inverse', text);
  if (scheme !== 'high-contrast') {
    const edge = contrast(values['--slotted-surface']!, values['--slotted-control-border-color']!);
    const strong = contrast(values['--slotted-surface']!, values['--slotted-border-strong']!);
    const disabled = contrast(values['--slotted-surface']!, values['--slotted-disabled-border']!);
    if (edge >= strong) failures.push('the control edge is not lighter than the strong border');
    if (disabled >= edge) failures.push('the disabled border is not lighter than the control edge');
  }
  for (const tone of TONES) {
    for (const state of ['solid', 'solid-hover', 'solid-active']) {
      pair(`--slotted-tone-${tone}-on-solid`, `--slotted-tone-${tone}-${state}`, text);
    }
    pair(`--slotted-tone-${tone}-text`, `--slotted-tone-${tone}-surface`, text);
  }
  pair('--slotted-tone-accent-border', '--slotted-surface', NON_TEXT);
  pair('--slotted-tone-accent-border', '--slotted-tone-accent-surface', NON_TEXT);
  pair('--slotted-disabled-foreground', '--slotted-disabled-background', NON_TEXT);
  return failures;
}

/** Hue 0–345 by 15, chroma 0–0.35 by 0.05, lightness 0.2–0.95 by 0.05: 3072 seeds. */
export function seedGrid(): Oklch[] {
  const seeds: Oklch[] = [];
  for (let h = 0; h < 360; h += 15) {
    for (const c of [0, 0.05, 0.1, 0.15, 0.2, 0.25, 0.3, 0.35]) {
      for (let step = 0; step < 16; step += 1) seeds.push({ l: 0.2 + step * 0.05, c, h });
    }
  }
  return seeds;
}
```

```js
import { readFile, writeFile } from 'node:fs/promises';
import { pathToFileURL } from 'node:url';

import {
  deltaE,
  evaluateRecipe,
  fitBound,
  parseSeed,
  relativeLuminance,
  SCHEMES,
  SEED_NAMES,
  seedGrid,
} from '../packages/theme/dist/index.js';

/**
 * Generates `recipes.standard` from the default theme's colours as they stood
 * before the recipe existed (`packages/themes/src/default/reference.json`):
 *
 * 1. each token becomes a derivation of its seed that reproduces its value —
 *    a `-solid`, `-solid-active`, `-border` or `-text` of a coloured tone
 *    follows the seed's lightness by an offset, every other token keeps a
 *    fixed lightness, a `-solid-hover` mixes its solid, a `var()` stays an alias;
 * 2. chroma is capped: 0.25 where the token follows the seed, 0.06 on the
 *    neutral, the reference chroma + 0.01 (at least 0.06) on a tinted surface;
 * 3. each solid, hover, active, tone text and the accent edge gets one bound
 *    per side, against the worst ground or ink of its scheme over `seedGrid()`.
 *
 * Run after `pnpm --filter @slotted/theme build`; rebuild afterwards.
 */

export const DEFAULT_SEEDS = {
  accent: '#1d4ed8',
  neutral: '#64748b',
  success: '#15803d',
  warning: '#facc15',
  danger: '#dc2626',
};

/** The share the hover moves toward white, per scheme — the rule of the retired `tone-hover.mjs`. */
const HOVER_SHARE = { light: 0.06, dark: 0.08, 'high-contrast': 0.06 };
const REQUIREMENT = { light: 4.5, dark: 4.5, 'high-contrast': 7 };
const TONE = /^--slotted-tone-(accent|secondary|success|warning|danger)-/;
const FOLLOWS_SEED = /-(solid|solid-active|border|text)$/;
const round = (value, digits) => Number(value.toFixed(digits));

function seedOf(token) {
  const match = TONE.exec(token);
  return !match || match[1] === 'secondary' ? 'neutral' : match[1];
}

function fit(reference, seeds) {
  const recipe = {};
  for (const scheme of SCHEMES) {
    recipe[scheme] = {};
    for (const [token, value] of Object.entries(reference[scheme])) {
      const alias = /^var\((--[a-z0-9-]+)\)$/.exec(value);
      if (alias) {
        recipe[scheme][token] = { alias: alias[1] };
        continue;
      }
      if (token.endsWith('-solid-hover')) {
        recipe[scheme][token] = { mix: token.replace(/-hover$/, ''), share: HOVER_SHARE[scheme] };
        continue;
      }
      const name = seedOf(token);
      const seed = seeds[name];
      const target = parseSeed(value);
      if (!target) throw new Error(`${scheme} ${token}: ${value} is not a seed notation`);
      const follows =
        name !== 'neutral' && !token.endsWith('-on-solid') && FOLLOWS_SEED.test(token) && target.c > 0.03;
      const scale = seed.c > 0 ? round(target.c / seed.c, 3) : 0;
      const max =
        target.c < 0.004
          ? 0
          : name === 'neutral'
            ? 0.06
            : follows
              ? 0.25
              : round(Math.max(0.06, target.c + 0.01), 3);
      let shift = target.h - seed.h;
      if (shift > 180) shift -= 360;
      if (shift < -180) shift += 360;
      recipe[scheme][token] = {
        seed: name,
        l: follows ? { offset: round(target.l - seed.l, 3) } : round(target.l, 3),
        c: { scale: target.c < 0.004 ? 0 : scale, max },
        ...(target.c >= 0.02 && Math.abs(shift) > 3 ? { h: Math.round(shift) } : {}),
      };
    }
    recipe[scheme]['--slotted-focus-ring-color'] = { alias: '--slotted-tone-accent-border' };
    recipe[scheme]['--slotted-focus-ring-color-invalid'] = { alias: '--slotted-tone-danger-border' };
  }
  return recipe;
}

/** The lowest and highest luminance a token takes over the grid of its own seed. */
function luminanceRange(recipe, seeds, scheme, token) {
  const rule = recipe[scheme][token];
  const varied = rule.seed ?? null;
  let low = 1;
  let high = 0;
  for (const seed of varied ? seedGrid() : [null]) {
    const values = evaluateRecipe(recipe, varied ? { ...seeds, [varied]: seed } : seeds, scheme);
    const { raw, clipped } = relativeLuminance(values[token]);
    low = Math.min(low, raw, clipped);
    high = Math.max(high, raw, clipped);
  }
  return [low, high];
}

function addBounds(recipe, seeds) {
  for (const scheme of SCHEMES) {
    const required = REQUIREMENT[scheme];
    const lightGround = scheme !== 'dark';
    const targets = {};
    const want = (token, side, target) => {
      const key = `${token}|${side}`;
      const stricter = side === 'ceiling' ? Math.min : Math.max;
      targets[key] = key in targets ? stricter(targets[key], target) : target;
    };
    const ranges = new Map();
    const range = (token) => {
      if (!ranges.has(token)) ranges.set(token, luminanceRange(recipe, seeds, scheme, `--slotted-${token}`));
      return ranges.get(token);
    };
    const against = (token, grounds, ratio) => {
      if (lightGround) {
        const lowest = Math.min(...grounds.map((ground) => range(ground)[0]));
        want(token, 'ceiling', (lowest + 0.05) / ratio - 0.05);
      } else {
        const highest = Math.max(...grounds.map((ground) => range(ground)[1]));
        want(token, 'floor', ratio * (highest + 0.05) - 0.05);
      }
    };
    for (const tone of ['accent', 'success', 'warning', 'danger']) {
      const [inkLow, inkHigh] = range(`tone-${tone}-on-solid`);
      const whiteInk = inkLow > 0.5;
      for (const state of ['solid', 'solid-hover', 'solid-active']) {
        if (whiteInk) want(`tone-${tone}-${state}`, 'ceiling', (inkLow + 0.05) / required - 0.05);
        else want(`tone-${tone}-${state}`, 'floor', required * (inkHigh + 0.05) - 0.05);
      }
      against(
        `tone-${tone}-text`,
        [`tone-${tone}-surface`, 'surface', 'surface-raised', 'surface-sunken'],
        required,
      );
    }
    against(
      'tone-accent-border',
      ['surface', 'surface-raised', 'surface-sunken', 'tone-accent-surface'],
      3,
    );
    for (const [key, target] of Object.entries(targets)) {
      const [token, side] = key.split('|');
      const rule = recipe[scheme][`--slotted-${token}`];
      if (!rule || 'alias' in rule) continue;
      rule.bounds = [...(rule.bounds ?? []), fitBound(target, side, 0.25)];
    }
  }
  return recipe;
}

export async function calibrate() {
  const reference = JSON.parse(
    await readFile(new URL('../packages/themes/src/default/reference.json', import.meta.url), 'utf8'),
  );
  const seeds = Object.fromEntries(SEED_NAMES.map((name) => [name, parseSeed(DEFAULT_SEEDS[name])]));
  const recipe = addBounds(fit(reference, seeds), seeds);

  const deviations = [];
  for (const scheme of SCHEMES) {
    const values = evaluateRecipe(recipe, seeds, scheme);
    for (const [token, value] of Object.entries(reference[scheme])) {
      if (value.startsWith('var(')) continue;
      const distance = deltaE(values[token], parseSeed(value));
      if (distance > 0.02) deviations.push({ scheme, token, from: value, distance: round(distance, 4) });
    }
  }
  return { recipe, deviations };
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  const { recipe, deviations } = await calibrate();
  const source =
    '// Generated by scripts/calibrate-standard-recipe.mjs from packages/themes/src/default/reference.json. Do not edit.\n' +
    "import type { Recipe } from '../recipe';\n\n" +
    `export const standard: Recipe = ${JSON.stringify(recipe, null, 2)};\n`;
  await writeFile(new URL('../packages/theme/src/recipes/standard.ts', import.meta.url), source);
  console.log(JSON.stringify(deviations, null, 2));
}
```

```ts
const REFERENCE = /var\(\s*(--[a-z0-9-]+)\s*(?:,([^()]*(?:\([^()]*\)[^()]*)*))?\)/i;

/**
 * Expands the `var()` references a token map makes to itself. It is not a CSS
 * engine: it resolves within one map, which is what one theme block is.
 */
export function resolveTokens(values: Readonly<Record<string, string>>): Record<string, string> {
  const resolved: Record<string, string> = { ...values };
  for (const name of Object.keys(resolved)) {
    resolved[name] = resolveValue(values, values[name]!, name, new Set([name]));
  }
  return resolved;
}

function resolveValue(
  values: Readonly<Record<string, string>>,
  value: string,
  name: string,
  path: ReadonlySet<string>,
): string {
  let current = value;
  while (REFERENCE.test(current)) {
    current = current.replace(REFERENCE, (_whole, reference: string, fallback?: string) => {
      if (reference in values) {
        if (path.has(reference)) throw new Error(`Reference cycle at ${reference}`);
        return resolveValue(values, values[reference]!, name, new Set([...path, reference]));
      }
      if (fallback !== undefined) return fallback.trim();
      throw new Error(`${name} references ${reference}, which the map does not hold`);
    });
  }
  return current;
}
```

```ts
import { parseSeed, toHex, type Oklch } from './color';
import {
  COMPONENT_TOKENS,
  contract,
  type BaseToken,
  type ComponentToken,
  type DensityToken,
  type MotionToken,
  type SchemeToken,
} from './generated/contract';
import { evaluateRecipe, SCHEMES, SEED_NAMES, type Recipe, type Scheme, type SeedName } from './recipe';
import { validateTheme, type FlatTheme } from './validate';

export const DENSITIES = ['comfortable', 'compact', 'dense'] as const;
export type Density = (typeof DENSITIES)[number];

type Values<T extends string> = Readonly<Partial<Record<T, string>>>;

export interface FontFaceDefinition {
  readonly family: string;
  /** A CSS `src` value, written as it would be in `@font-face`. */
  readonly src: string;
  readonly weight?: string;
  readonly style?: string;
  readonly display?: 'auto' | 'block' | 'swap' | 'fallback' | 'optional';
}

export interface ThemeDefinition {
  readonly name: string;
  readonly seeds: Readonly<Record<SeedName, string>>;
  readonly recipe: Recipe;
  readonly base?: Values<BaseToken>;
  readonly schemes?: Readonly<Partial<Record<Scheme, Values<SchemeToken>>>>;
  readonly densities?: Readonly<Partial<Record<Density, Values<DensityToken>>>>;
  readonly reducedMotion?: Values<MotionToken>;
  readonly components?: Values<ComponentToken>;
  readonly fonts?: readonly FontFaceDefinition[];
  /** CSS text, or the URL of a `.css` file the CLI reads at build time. */
  readonly rules?: readonly (string | URL)[];
}

export interface Theme extends ThemeDefinition {
  readonly kind: 'slotted-theme';
}

export type ThemeOverrides = Omit<Partial<ThemeDefinition>, 'name' | 'seeds'> & {
  readonly name: string;
  readonly seeds?: Readonly<Partial<Record<SeedName, string>>>;
};

const NAME = /^[a-z][a-z0-9-]*$/;

function deepFreeze<T>(value: T): T {
  if (value && typeof value === 'object' && !(value instanceof URL) && !Object.isFrozen(value)) {
    Object.freeze(value);
    for (const child of Object.values(value)) deepFreeze(child);
  }
  return value;
}

function parsedSeeds(seeds: ThemeDefinition['seeds']): Record<SeedName, Oklch> {
  return Object.fromEntries(SEED_NAMES.map((name) => [name, parseSeed(seeds[name])!])) as Record<
    SeedName,
    Oklch
  >;
}

/**
 * The theme as the contract reads it: every scheme with the recipe evaluated —
 * an alias as its `var()`, every other derivation as the hex it computes to
 * with the theme's own seeds — and the theme's scheme values laid over it.
 */
export function flattenTheme(theme: ThemeDefinition): FlatTheme {
  const seeds = parsedSeeds(theme.seeds);
  const schemes = Object.fromEntries(
    SCHEMES.map((scheme) => {
      const derived = evaluateRecipe(theme.recipe, seeds, scheme);
      const values: Record<string, string> = {};
      for (const [name, rule] of Object.entries(theme.recipe[scheme])) {
        values[name] = 'alias' in rule ? `var(${rule.alias})` : toHex(derived[name]!);
      }
      return [scheme, { ...values, ...(theme.schemes?.[scheme] ?? {}) }];
    }),
  );
  return {
    name: theme.name,
    base: { ...(theme.base ?? {}) },
    schemes,
    densities: Object.fromEntries(
      Object.entries(theme.densities ?? {}).map(([density, values]) => [density, { ...values }]),
    ),
    reducedMotion: { ...(theme.reducedMotion ?? {}) },
  };
}

export function defineTheme(definition: ThemeDefinition): Theme {
  const errors: string[] = [];
  if (!NAME.test(definition.name)) {
    errors.push(`name ${JSON.stringify(definition.name)} is not [a-z][a-z0-9-]*`);
  }
  for (const seed of SEED_NAMES) {
    const value = definition.seeds?.[seed];
    if (typeof value !== 'string' || parseSeed(value) === null) {
      errors.push(`seed ${seed} ${JSON.stringify(value)} is neither #rrggbb nor oklch(L C H)`);
    }
  }
  const components = new Set<string>(COMPONENT_TOKENS);
  for (const name of Object.keys(definition.components ?? {})) {
    if (!components.has(name)) errors.push(`components contains ${name}, which no family reads`);
  }
  const schemeTokens = new Set(contract.tokens.filter((token) => token.axis === 'scheme').map((token) => token.name));
  for (const scheme of SCHEMES) {
    for (const name of Object.keys(definition.recipe?.[scheme] ?? {})) {
      if (!schemeTokens.has(name)) errors.push(`recipe ${scheme} derives ${name}, which no scheme carries`);
    }
  }
  for (const rule of definition.rules ?? []) {
    if (typeof rule !== 'string' && !(rule instanceof URL)) errors.push('a rule is neither CSS text nor a URL');
  }
  if (errors.length === 0) {
    try {
      errors.push(...validateTheme(contract, flattenTheme(definition)));
    } catch (error) {
      errors.push((error as Error).message);
    }
  }
  if (errors.length > 0) {
    throw new Error(`Invalid theme ${definition.name}:\n${errors.map((error) => `- ${error}`).join('\n')}`);
  }
  const { kind: _kind, ...plain } = definition as ThemeDefinition & { kind?: string };
  return deepFreeze({ ...plain, kind: 'slotted-theme' as const });
}

function mergeNested<K extends string, V extends object>(
  base: Readonly<Partial<Record<K, V>>> | undefined,
  overrides: Readonly<Partial<Record<K, V>>> | undefined,
): Partial<Record<K, V>> {
  const merged: Partial<Record<K, V>> = { ...(base ?? {}) };
  for (const [key, value] of Object.entries(overrides ?? {}) as [K, V][]) {
    merged[key] = { ...(merged[key] ?? {}), ...value } as V;
  }
  return merged;
}

/** A theme built on another: values merged key by key, fonts and rules appended. */
export function extendTheme(base: Theme, overrides: ThemeOverrides): Theme {
  const { kind: _kind, ...parent } = base;
  return defineTheme({
    ...parent,
    name: overrides.name,
    seeds: { ...parent.seeds, ...(overrides.seeds ?? {}) },
    recipe: overrides.recipe ?? parent.recipe,
    base: { ...(parent.base ?? {}), ...(overrides.base ?? {}) },
    schemes: mergeNested(parent.schemes, overrides.schemes),
    densities: mergeNested(parent.densities, overrides.densities),
    reducedMotion: { ...(parent.reducedMotion ?? {}), ...(overrides.reducedMotion ?? {}) },
    components: { ...(parent.components ?? {}), ...(overrides.components ?? {}) },
    fonts: [...(parent.fonts ?? []), ...(overrides.fonts ?? [])],
    rules: [...(parent.rules ?? []), ...(overrides.rules ?? [])],
  });
}
```

```ts
/**
 * Splits CSS into its top-level statements: a block ends at the brace that
 * returns to depth 0, an at-statement at the semicolon. Strings and comments
 * are skipped, so a brace inside `content: "}"` does not end a rule.
 */
export function splitTopLevel(css: string): string[] {
  const statements: string[] = [];
  let depth = 0;
  let start = 0;
  let quote: string | null = null;
  for (let index = 0; index < css.length; index += 1) {
    const char = css[index]!;
    if (quote) {
      if (char === '\\') index += 1;
      else if (char === quote) quote = null;
      continue;
    }
    if (char === '/' && css[index + 1] === '*') {
      const end = css.indexOf('*/', index + 2);
      const stop = end === -1 ? css.length : end + 2;
      if (depth === 0) {
        statements.push(css.slice(start, index));
        start = stop;
      }
      index = stop - 1;
      continue;
    }
    if (char === '"' || char === "'") quote = char;
    else if (char === '{') depth += 1;
    else if (char === '}') {
      depth -= 1;
      if (depth === 0) {
        statements.push(css.slice(start, index + 1));
        start = index + 1;
      }
    } else if (char === ';' && depth === 0) {
      statements.push(css.slice(start, index + 1));
      start = index + 1;
    }
  }
  statements.push(css.slice(start));
  return statements.map((statement) => statement.trim()).filter(Boolean);
}

const REFUSED = /^@(import|layer|scope)\b/i;
const HOISTED = /^@(font-face|property)\b/i;
const KEYFRAMES = /^@keyframes\s+([\w-]+)/i;

/**
 * The rules of one theme, ready for the compiler: `@keyframes`, `@font-face`
 * and `@property` leave the scope they cannot live in, and every keyframes
 * name takes the theme's prefix so two themes on one page never collide.
 */
export function processRules(
  themeName: string,
  sources: readonly string[],
): { hoisted: string[]; body: string } {
  const statements = sources.flatMap(splitTopLevel);
  const names = new Map<string, string>();
  for (const statement of statements) {
    const match = KEYFRAMES.exec(statement);
    if (match) names.set(match[1]!, `slotted-${themeName}-${match[1]}`);
  }
  const rename = (statement: string) =>
    statement.replace(/(animation(?:-name)?\s*:\s*)([^;}]*)/g, (_whole, property: string, value: string) =>
      property + value.replace(/[\w-]+/g, (word) => names.get(word) ?? word),
    );

  const hoisted: string[] = [];
  const body: string[] = [];
  for (const statement of statements) {
    const refused = REFUSED.exec(statement);
    if (refused) {
      throw new Error(
        `${themeName}: @${refused[1]} is written by the compiler; a theme rule cannot carry its own`,
      );
    }
    const keyframes = KEYFRAMES.exec(statement);
    if (keyframes) hoisted.push(statement.replace(KEYFRAMES, `@keyframes ${names.get(keyframes[1]!)}`));
    else if (HOISTED.test(statement)) hoisted.push(statement);
    else body.push(rename(statement));
  }
  return { hoisted, body: body.join('\n\n') };
}
```

```ts
import { DENSITIES, type FontFaceDefinition, type Theme } from './define';
import { contract } from './generated/contract';
import { LAYER_ORDER_STATEMENT } from './layer-order';
import { derivationCss, SCHEMES, SEED_NAMES, type Scheme } from './recipe';
import { processRules } from './rules';

/** `high-contrast` paints black on white, so the light user-agent style matches it. */
const UA_SCHEME: Readonly<Record<Scheme, 'light' | 'dark'>> = {
  light: 'light',
  dark: 'dark',
  'high-contrast': 'light',
};

const indent = (text: string, spaces = 2) =>
  text
    .split('\n')
    .map((line) => (line ? ' '.repeat(spaces) + line : line))
    .join('\n');
const block = (selectors: readonly string[], body: string) =>
  `${selectors.join(',\n')} {\n${indent(body)}\n}`;
const declarations = (values: Readonly<Record<string, string>>) =>
  Object.entries(values)
    .map(([name, value]) => `${name}: ${value};`)
    .join('\n');
const themeSelector = (name: string) => `[data-slotted-theme="${name}"]`;
const schemeSelector = (scheme: string) => `[data-slotted-scheme="${scheme}"]`;

/**
 * One scheme, scoped to the nearest element that names it. The limit stops at
 * any element that names another scheme or theme, and scoping proximity makes
 * the nearest root win when two schemes are nested. `[data-slotted-seeds]`
 * re-derives every colour from the seeds an element carries itself.
 */
function schemeScope(theme: string, scheme: string, body: string): string {
  const t = themeSelector(theme);
  const s = schemeSelector(scheme);
  return (
    `@scope (${t}${s}, ${t} ${s}, ${s} ${t}) to ([data-slotted-scheme], [data-slotted-theme]) {\n` +
    `${indent(block([':scope', '[data-slotted-seeds]'], body))}\n}`
  );
}

function schemeValues(theme: Theme, scheme: Scheme): Record<string, string> {
  const values: Record<string, string> = {};
  for (const [name, rule] of Object.entries(theme.recipe[scheme])) values[name] = derivationCss(rule);
  return { ...values, ...(theme.schemes?.[scheme] ?? {}) };
}

function densitySelectors(theme: string, density: string): string[] {
  const t = themeSelector(theme);
  const d = `[data-slotted-density="${density}"]`;
  return [`${t}${d}`, `${t} ${d}`];
}

const propertyRule = (seed: string) =>
  `@property --slotted-seed-${seed} {\n  syntax: '<color>';\n  inherits: true;\n  initial-value: gray;\n}`;

const fontFace = (font: FontFaceDefinition) =>
  `@font-face {\n  font-family: ${JSON.stringify(font.family)};\n  src: ${font.src};\n` +
  `  font-weight: ${font.weight ?? 'normal'};\n  font-style: ${font.style ?? 'normal'};\n` +
  `  font-display: ${font.display ?? 'swap'};\n}`;

export function renderTheme(theme: Theme): string {
  for (const rule of theme.rules ?? []) {
    if (typeof rule !== 'string') {
      throw new Error(`${theme.name}: a rule is still a URL (${rule.href}); build the theme with slotted-build-theme`);
    }
  }
  const name = theme.name;
  const seeds = Object.fromEntries(SEED_NAMES.map((seed) => [`--slotted-seed-${seed}`, theme.seeds[seed]]));
  const blocks: string[] = [
    block([themeSelector(name)], declarations({ ...seeds, ...(theme.base ?? {}), ...(theme.components ?? {}) })),
  ];

  for (const scheme of SCHEMES) {
    blocks.push(schemeScope(name, scheme, `color-scheme: ${UA_SCHEME[scheme]};\n${declarations(schemeValues(theme, scheme))}`));
  }
  blocks.push(schemeScope(name, 'system', `color-scheme: light;\n${declarations(schemeValues(theme, 'light'))}`));
  blocks.push(
    `@media (prefers-color-scheme: dark) {\n${indent(
      schemeScope(name, 'system', `color-scheme: dark;\n${declarations(schemeValues(theme, 'dark'))}`),
    )}\n}`,
  );

  for (const density of DENSITIES) {
    blocks.push(block(densitySelectors(name, density), declarations(theme.densities?.[density] ?? {})));
  }

  /* A coarse pointer cannot hit what a mouse can: controls grow to the comfortable target. */
  const targets = contract.tokens
    .filter((token) => token.axis === 'density' && /^--slotted-control-height-(sm|md|lg)$/.test(token.name))
    .map((token) => token.name);
  blocks.push(
    `@media (pointer: coarse) {\n${indent(
      DENSITIES.map((density) =>
        block(
          densitySelectors(name, density),
          targets
            .map((token) => `${token}: max(${theme.densities?.[density]?.[token as never]}, var(--slotted-target-comfortable));`)
            .join('\n'),
        ),
      ).join('\n\n'),
    )}\n}`,
  );

  /* Forced colours replace the palette; the same scopes carry the system colours, later in source. */
  const forced = declarations(
    Object.fromEntries(
      contract.tokens.filter((token) => token.axis === 'scheme').map((token) => [token.name, token.forcedColor!]),
    ),
  );
  blocks.push(
    `@media (forced-colors: active) {\n${indent(
      [block([themeSelector(name)], forced), ...[...SCHEMES, 'system'].map((scheme) => schemeScope(name, scheme, forced))].join('\n\n'),
    )}\n}`,
  );

  /* Last in the layer: a media query adds no specificity, so source order makes it win. */
  blocks.push(
    `@media (prefers-reduced-motion: reduce) {\n${indent(
      block([themeSelector(name)], declarations(theme.reducedMotion ?? {})),
    )}\n}`,
  );

  const { hoisted, body } = processRules(name, (theme.rules ?? []) as readonly string[]);
  const parts = [
    LAYER_ORDER_STATEMENT.trimEnd(),
    ...SEED_NAMES.map(propertyRule),
    ...(theme.fonts ?? []).map(fontFace),
    `@layer slotted.theme {\n${indent(blocks.join('\n\n'))}\n}`,
    ...hoisted,
  ];
  if (body) {
    parts.push(
      `@layer slotted.theme-rules {\n${indent(
        `@scope (${themeSelector(name)}) to ([data-slotted-theme]:not(${themeSelector(name)})) {\n${indent(body)}\n}`,
      )}\n}`,
    );
  }
  return `${parts.join('\n\n')}\n`;
}
```

```js
import { readFileSync } from 'node:fs';

import { transform } from 'lightningcss';

import { COMPONENT_TOKENS, contract, SEED_NAMES } from '../dist/index.js';

/**
 * A theme rule may select only what a binding renders on purpose — a family by
 * `data-ui`, its parts by `data-part`, and the attributes a family or the
 * theme axes set — and may read only tokens. Everything else is an
 * implementation detail of a family stylesheet, which changes without notice.
 */
const hooks = JSON.parse(readFileSync(new URL('../src/generated/hooks.json', import.meta.url), 'utf8'));
const ATTRIBUTES = new Set([
  ...hooks.attributes,
  'data-ui',
  'data-part',
  'data-slotted-theme',
  'data-slotted-scheme',
  'data-slotted-density',
  'data-slotted-seeds',
]);
const TOKENS = new Set([
  ...contract.tokens.map((token) => token.name),
  ...COMPONENT_TOKENS,
  ...SEED_NAMES.map((seed) => `--slotted-seed-${seed}`),
]);

const at = (filename, loc) => `${filename}:${(loc?.line ?? 0) + 1}:${loc?.column ?? 0}`;

function checkSelector(components, where, report) {
  let ui = null;
  let part = null;
  const closeCompound = () => {
    if (ui && part && !(hooks.ui[ui] ?? []).includes(part)) {
      report(where, `[data-part='${part}'] is not a part of ${ui}`);
    }
    ui = null;
    part = null;
  };
  for (const component of components) {
    if (component.type === 'combinator') {
      closeCompound();
      continue;
    }
    if (component.type === 'class') report(where, `.${component.name}: a class is not a public selector`);
    if (component.type === 'attribute') {
      const value = component.operation?.value;
      if (component.name === 'data-ui') {
        if (value !== undefined && !(value in hooks.ui)) report(where, `[data-ui='${value}'] names no family`);
        ui = value ?? null;
      } else if (component.name === 'data-part') {
        part = value ?? null;
      } else if (component.name.startsWith('data-') && !ATTRIBUTES.has(component.name)) {
        report(where, `[${component.name}] is not an attribute any family sets`);
      }
    }
    for (const nested of component.selectors ?? []) checkSelector(nested, where, report);
  }
  closeCompound();
}

export function validateRules(css, filename) {
  const errors = [];
  const report = (where, message) => errors.push(`${where} ${message}`);
  try {
    transform({
      filename,
      code: Buffer.from(css),
      errorRecovery: false,
      visitor: {
        Rule: {
          style(rule) {
            const where = at(filename, rule.value.loc);
            for (const selector of rule.value.selectors) checkSelector(selector, where, report);
            return rule;
          },
        },
        Variable(variable) {
          const name = variable.name.ident;
          if (name.startsWith('--_')) report(filename, `var(${name}) reads a private property of a family`);
          else if (name.startsWith('--slotted-') && !TOKENS.has(name)) report(filename, `var(${name}) is not a token`);
          return variable;
        },
      },
    });
  } catch (error) {
    errors.push(`${at(filename, error.loc)} ${error.message}`);
  }
  return errors;
}
```

```js
import { mkdir, readFile, writeFile } from 'node:fs/promises';
import { resolve } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';

import { defineTheme, renderTheme } from '../dist/index.js';
import { validateRules } from './validate-rules.mjs';

/**
 * Builds one theme module into `<name>.css`, `<name>.js` and `<name>.d.ts`. A
 * rule given as a URL is read here, so the published module carries every
 * rule as text and `applyTheme` never fetches.
 */
export async function buildTheme(modulePath, outDir) {
  const theme = (await import(pathToFileURL(resolve(modulePath)).href)).default;
  if (theme?.kind !== 'slotted-theme') {
    throw new Error(`${modulePath}: the default export is not a theme from defineTheme`);
  }
  const errors = [];
  const rules = [];
  for (const [index, rule] of (theme.rules ?? []).entries()) {
    const text = typeof rule === 'string' ? rule : await readFile(rule, 'utf8');
    const filename = typeof rule === 'string' ? `${modulePath}#rules[${index}]` : fileURLToPath(rule);
    errors.push(...validateRules(text, filename));
    rules.push(text);
  }
  if (errors.length > 0) {
    throw new Error(`Invalid theme rules:\n${errors.map((error) => `- ${error}`).join('\n')}`);
  }
  const { kind: _kind, ...definition } = theme;
  const built = defineTheme({ ...definition, rules });
  const css = renderTheme(built);
  await mkdir(resolve(outDir), { recursive: true });
  await writeFile(resolve(outDir, `${built.name}.css`), css);
  await writeFile(resolve(outDir, `${built.name}.js`), `export default ${JSON.stringify(built, null, 2)};\n`);
  await writeFile(
    resolve(outDir, `${built.name}.d.ts`),
    "import type { Theme } from '@slotted/theme';\n\ndeclare const theme: Theme;\nexport default theme;\n",
  );
  return { name: built.name, css };
}
```

```ts
import { parseSeed } from './color';
import type { Theme } from './define';
import { SEED_NAMES, type SeedName } from './recipe';
import { renderTheme } from './render';

/** Dispatched on the document when a theme stylesheet is applied or removed. */
export const THEME_CHANGE_EVENT = 'slotted-themechange';

export interface ThemeChangeDetail {
  readonly name: string;
  readonly applied: boolean;
}

/**
 * Puts a theme on the page without a build: one `<style>` per theme name in
 * the head, replaced in place when the same name is applied again. The
 * returned function removes it.
 */
export function applyTheme(theme: Theme, options: { readonly document?: Document } = {}): () => void {
  const doc = options.document ?? globalThis.document;
  if (!doc) throw new Error(`${theme.name}: applyTheme needs a document`);
  const css = renderTheme(theme);
  let sheet = doc.head.querySelector<HTMLStyleElement>(`style[data-slotted-theme-sheet="${theme.name}"]`);
  if (!sheet) {
    sheet = doc.createElement('style');
    sheet.setAttribute('data-slotted-theme-sheet', theme.name);
    doc.head.append(sheet);
  }
  if (sheet.textContent !== css) sheet.textContent = css;

  const announce = (applied: boolean) =>
    doc.dispatchEvent(
      new CustomEvent<ThemeChangeDetail>(THEME_CHANGE_EVENT, { detail: { name: theme.name, applied } }),
    );
  announce(true);

  const element = sheet;
  return () => {
    if (!element.isConnected) return;
    element.remove();
    announce(false);
  };
}

/** The `style` object that gives an element its own seeds, for React `style` and Angular `[style]`. */
export function seedStyle(seeds: Readonly<Partial<Record<SeedName, string>>>): Record<string, string> {
  const style: Record<string, string> = {};
  for (const name of SEED_NAMES) {
    const value = seeds[name];
    if (value === undefined) continue;
    if (parseSeed(value) === null) {
      throw new Error(`seed ${name} ${JSON.stringify(value)} is neither #rrggbb nor oklch(L C H)`);
    }
    style[`--slotted-seed-${name}`] = value;
  }
  return style;
}
```

```ts
function mirror(layer: Element, origin: Element | null) {
  for (const attribute of MIRRORED_ATTRIBUTES) {
    const value = inherited(origin, attribute);
    if (value === layer.getAttribute(attribute)) continue;
    if (value === null) layer.removeAttribute(attribute);
    else layer.setAttribute(attribute, value);
  }
  mirrorSeeds(layer, origin);
}

function mirrorSeeds(layer: Element, origin: Element | null) {
  const view = layer.ownerDocument.defaultView;
  const style = (layer as HTMLElement).style as CSSStyleDeclaration | undefined;
  if (!view || !style) return;
  const computed = origin ? view.getComputedStyle(origin) : null;
  let carried = false;
  for (const property of MIRRORED_PROPERTIES) {
    const value = computed?.getPropertyValue(property).trim() ?? '';
    if (value) {
      carried = true;
      if (style.getPropertyValue(property) !== value) style.setProperty(property, value);
    } else if (style.getPropertyValue(property)) {
      style.removeProperty(property);
    }
  }
  if (carried && !layer.hasAttribute('data-slotted-seeds')) layer.setAttribute('data-slotted-seeds', '');
  if (!carried && layer.hasAttribute('data-slotted-seeds')) layer.removeAttribute('data-slotted-seeds');
}
```

```tsx
import type { CSSProperties, HTMLAttributes, ReactNode } from 'react';

/** The five seeds a theme derives its colours from (`@slotted/theme` › `SEED_NAMES`). */
export type ThemeSeedName = 'accent' | 'neutral' | 'success' | 'warning' | 'danger';
export type ThemeSchemeName = 'light' | 'dark' | 'high-contrast' | 'system';
export type ThemeDensityName = 'comfortable' | 'compact' | 'dense';

export interface ThemeScopeProps extends HTMLAttributes<HTMLElement> {
  /** The theme the subtree uses: the `name` of a loaded theme stylesheet. */
  theme?: string | undefined;
  scheme?: ThemeSchemeName | undefined;
  density?: ThemeDensityName | undefined;
  /** Seeds for this subtree. Every colour below is derived from them again. */
  seeds?: Readonly<Partial<Record<ThemeSeedName, string>>> | undefined;
  /** Renders another element in place of the `div`, with these props. */
  render?: ((props: HTMLAttributes<HTMLElement>) => ReactNode) | undefined;
  children?: ReactNode;
}

/**
 * A subtree with its own theme, scheme, density or seeds. It writes the same
 * attributes and custom properties an application can write by hand; an
 * overlay opened inside it carries them to the end of the body.
 */
export function ThemeScope({ theme, scheme, density, seeds, render, style, ...rest }: ThemeScopeProps) {
  const seedProperties = Object.fromEntries(
    Object.entries(seeds ?? {})
      .filter(([, value]) => value !== undefined)
      .map(([name, value]) => [`--slotted-seed-${name}`, value]),
  );
  const seeded = Object.keys(seedProperties).length > 0;
  const props = {
    ...rest,
    'data-slotted-theme': theme,
    'data-slotted-scheme': scheme,
    'data-slotted-density': density,
    'data-slotted-seeds': seeded ? '' : undefined,
    style: seeded ? ({ ...seedProperties, ...style } as CSSProperties) : style,
  } as HTMLAttributes<HTMLElement>;
  return render ? render(props) : <div {...(props as HTMLAttributes<HTMLDivElement>)} />;
}
```

```ts
/** The five seeds a theme derives its colours from (`@slotted/theme` › `SEED_NAMES`). */
export type ThemeSeedName = 'accent' | 'neutral' | 'success' | 'warning' | 'danger';
export type ThemeSchemeName = 'light' | 'dark' | 'high-contrast' | 'system';
export type ThemeDensityName = 'comfortable' | 'compact' | 'dense';

/**
 * A subtree with its own theme, scheme, density or seeds, written on the host
 * as the attributes and custom properties an application can write by hand.
 */
@Directive({
  selector: '[slThemeScope]',
  host: {
    '[attr.data-slotted-theme]': 'theme() ?? null',
    '[attr.data-slotted-scheme]': 'scheme() ?? null',
    '[attr.data-slotted-density]': 'density() ?? null',
    '[attr.data-slotted-seeds]': "seedProperties() ? '' : null",

  },
})
export class SlThemeScope {
  readonly theme = input<string | undefined>(undefined);
  readonly scheme = input<ThemeSchemeName | undefined>(undefined);
  readonly density = input<ThemeDensityName | undefined>(undefined);

    const entries = Object.entries(this.seeds() ?? {})
      .filter(([, value]) => value !== undefined)

  });
}
```

```js
 * scopes. Every colour token of the recipe is read through a probe's `color`,
 * whose computed value keeps OKLCH unclipped.
 *
 * Run: node tools/harness/scenarios/theme-recipe-parity.mjs
 * Exits non-zero when an assertion fails.
 */

const TOLERANCE = 0.005;
const samples = seedGrid().filter((_seed, index) => index % 48 === 0);
const tokens = Object.keys(defaultTheme.recipe.light);
const seeds = Object.fromEntries(SEED_NAMES.map((name) => [name, parseSeed(defaultTheme.seeds[name])]));
const css = (seed) => `oklch(${seed.l} ${seed.c} ${seed.h})`;

const cases = [];
for (const scheme of SCHEMES) {
  for (const name of SEED_NAMES) {
    for (const sample of samples) cases.push({ scheme, name, sample });
  }
}

const scopes = cases
  .map(
    ({ scheme, name, sample }, index) =>
      `<div data-case="${index}" data-slotted-theme="default" data-slotted-scheme="${scheme}" style="--slotted-seed-${name}: ${css(sample)}"><i></i></div>`,
  )
  .join('\n');
const page = `<!doctype html><html><head><style>${renderTheme(defaultTheme)}</style></head><body>${scopes}</body></html>`;

const out = new URL('../out/theme-recipe-parity.html', import.meta.url);
await mkdir(new URL('.', out), { recursive: true });
await writeFile(out, page);

const READ = `[...document.querySelectorAll('[data-case]')].map((scope) => {
  const probe = scope.querySelector('i');
  return ${JSON.stringify(tokens)}.map((token) => {
    probe.style.color = 'var(' + token + ')';
    return getComputedStyle(probe).color;
  });
})`;

const { devtools, close } = await launch();
let readings;
try {
  await devtools.send('Page.enable');
  await devtools.send('Runtime.enable');
  const loaded = devtools.once('Page.loadEventFired');
  await devtools.send('Page.navigate', { url: pathToFileURL(out.pathname).href });
  await loaded;
  const { result, exceptionDetails } = await devtools.send('Runtime.evaluate', {
    expression: READ,
    returnByValue: true,
  });
  if (exceptionDetails) throw new Error(exceptionDetails.exception?.description ?? 'the read failed');
  readings = result.value;
} finally {
  devtools.close();
  await close();
}

function parseComputed(text) {
  const match = /^oklch\(([\d.e-]+|none) ([\d.e-]+|none) ([\d.e-]+|none)/.exec(text);
  assert.ok(match, `the browser wrote ${text}, not oklch()`);
  const number = (value) => (value === 'none' ? 0 : Number(value));
  return { l: number(match[1]), c: number(match[2]), h: number(match[3]) };
}

const failures = [];
cases.forEach(({ scheme, name, sample }, index) => {
  const expected = evaluateRecipe(defaultTheme.recipe, { ...seeds, [name]: sample }, scheme);
  tokens.forEach((token, column) => {
    const distance = deltaE(parseComputed(readings[index][column]), expected[token]);
    if (distance >= TOLERANCE) {
      failures.push(`${scheme} ${name}=${css(sample)} ${token}: ${readings[index][column]} is ${distance.toFixed(4)} from the evaluator`);
    }
  });
});

assert.deepEqual(failures.slice(0, 20), [], `${failures.length} tokens disagree`);
console.log(`ok — ${cases.length} scopes × ${tokens.length} tokens agree within ${TOLERANCE}`);
```

```markdown
# 0004 — Theming architecture

Status: accepted, 2026-10-01. Design: `docs/history/designs/2026-10-01-theming-architecture-design.md`. Supersedes the sublayer table of `0001-cascade-layer-contract.md`.

## Context

A theme was a JSON file of literal token values. It could not carry a rule, a font or a component-level decision, and changing the accent meant editing nine tokens in each of three schemes. No colour could be chosen at runtime.

## Decision

**A theme is a module.** `defineTheme` from `@slotted/theme` takes seeds, a recipe, token values on the three axes, component tokens, fonts and CSS rules, and is typed against the token contract and the component tokens the family stylesheets read. `extendTheme` builds one theme on another. `slotted-build-theme` compiles a theme module to `<name>.css`, `<name>.js` and `<name>.d.ts`; `applyTheme` compiles and applies one at runtime.

**Colour is derived from seeds in CSS.** Five seeds (`accent`, `neutral`, `success`, `warning`, `danger`) are registered custom properties. Every colour token is an `oklch(from var(--slotted-seed-*) …)` derivation with a lightness bound that depends on hue and chroma, so any seed keeps the contrast ratios; `evaluateRecipe` computes the same values in JavaScript.

**Schemes are scoped.** Each scheme block is an `@scope` whose nearest root wins; an element with `data-slotted-seeds` derives every colour from its own seeds. `data-slotted-scheme="system"` follows `prefers-color-scheme`.

**Theme rules have their own sublayer.** The published order is `@layer slotted.reset, slotted.tokens, slotted.theme, slotted.components, slotted.theme-rules;`. A theme's rules are emitted inside `@scope ([data-slotted-theme="<name>"]) to ([data-slotted-theme]:not([data-slotted-theme="<name>"]))` and may select only `data-ui`, `data-part` and the public attributes, and read only tokens.

## Consequences

- Minimum browsers: Chrome 119, Safari 18, Firefox 146.
- `@slotted/tokens` and `@slotted/theme-default` are gone; `@slotted/theme` and `@slotted/themes` replace them.
- A family that adds a component token makes `pnpm --filter @slotted/theme generate` necessary; `packages/theme/test/generated.test.mjs` fails until it runs.
```
