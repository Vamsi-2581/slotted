from the family. The delta against what shipped is the last section.

## 2. Table stakes

Every capability two or more of the eleven ship.

| Capability                                                          | Who ships it                                                       | Verdict            | Reason                                                                                                                                                     |
| ------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Label bound to the control by `for`                                 | all eleven                                                         | adopt              | `fieldLabel`, whose `for` is derived from the field's base identifier.                                                                                      |
| Description that joins `aria-describedby`                           | all eleven                                                         | adopt              | `fieldDescription`, rendering `inline-message` at tone `secondary`.                                                                                        |
| Error that joins `aria-describedby`                                 | all eleven                                                         | adopt              | `fieldError`, rendering `inline-message` at tone `danger`.                                                                                                  |
| Generated identifiers with an explicit override                     | Base UI, Ark, Fluent, Primer, Angular Material                     | adopt              | One base identifier, four derived; a consumer's `id` replaces the base and every derived value follows.                                                     |
| `disabled` shared by the field with its control                     | Base UI, Ark, Chakra, Fluent, Primer                               | adopt              | Native `disabled`, per the field-aware-controls design.                                                                                                     |
| `invalid` shared by the field with its control                      | Base UI, Ark, Chakra, Fluent, Mantine                              | adopt              | `aria-invalid` on the control, `data-invalid` on the field.                                                                                                 |
| `required` shared by the field with its control                     | Base UI, Ark, Chakra, Fluent, Spectrum                             | adopt              | `aria-required`, never native `required`, per the field-aware-controls design.                                                                              |
| `readOnly` shared by the field with its control                     | Ark, Chakra                                                        | adopt              | Native `readonly`; `readonly` sits above `invalid` in `STATE_PRECEDENCE`.                                                                                    |
| Required marker drawn on the label                                  | Ark, Chakra, Fluent, Mantine, Spectrum, Angular Material           | adopt              | `mark` part inside `fieldLabel`, `aria-hidden`, because `aria-required` already carries the semantics.                                                        |
| Marker suppressible for a form where everything is required         | Angular Material (`hideRequiredMarker`), Mantine (`withAsterisk`)  | adopt              | `requiredMark="none"`, and settable once for the application.                                                                                                |
| Necessity as words rather than a glyph                              | Spectrum (`necessityIndicator="label"`), Ark and Chakra (`fallback`) | adopt            | `requiredMark="text"` writes `(required)` on a required field and `(optional)` on one that is not; both words are in the defaults so they translate once.    |
| Label beside the control instead of above it                        | Fluent (`orientation`), Primer (`layout`), Spectrum (`labelPosition`), Chakra | adopt   | `labelPlacement="side"`, which is the `placement` capability in the shared vocabulary.                                                                        |
| Label alignment when it sits beside the control                     | Spectrum (`labelAlign`)                                            | adapt              | Folded into `labelPlacement`: the side label is start-aligned to the control's first line, which is the only alignment that survives a wrapping label.        |
| An explicit control wrapper for a control the library does not own  | Base UI (`Field.Control`), Ark (`getInputProps`), Fluent (render child) | adopt          | `fieldControl`, exactly as the field-primitive design specifies.                                                                                             |
| Space reserved for the message so nothing moves when it arrives     | Angular Material (`subscriptSizing="fixed"`)                       | adopt              | `inline-message`'s own `reserve`, passed through by `fieldError`.                                                                                            |
| Error replaces the description while the field is invalid           | Spectrum, Carbon                                                   | decline            | Both parts stay rendered and both stay in `aria-describedby`; a description that states the format is what a reader needs most at the moment of the error. A consumer wanting the replacement writes `{invalid ? null : <FieldDescription/>}` — two lines, and their decision. |
| A severity that is not an error (warning, success)                  | Fluent (`validationState`), Carbon                                 | adapt              | `fieldError` takes `inline-message`'s five tones, so a warning is `tone="warning"` on the same part rather than a fourth message member.                     |
| Grouping by native `fieldset` and `legend`                          | Base UI, Ark, GOV.UK, HTML                                         | adopt              | `field-group` renders `fieldset` and `legend`; the `group` role and the accessible name come from the platform.                                              |
| Group-level description and error                                   | Ark (`Fieldset.HelperText` / `ErrorText`), GOV.UK                  | adopt              | Both join the `fieldset`'s own `aria-describedby`, which is where GOV.UK puts them, and both precede the controls.                                          |
| Group `disabled` disabling every control inside                     | Ark, HTML                                                          | adopt              | Native `fieldset[disabled]`; nothing is propagated because the platform already does it.                                                                     |
| Group `invalid`                                                     | Ark, Base UI (`Fieldset` state)                                    | adopt              | `data-invalid` on the fieldset and on the fields it provides for.                                                                                            |
| Character counter beside the field's own text                       | Angular Material (`mat-hint align="end"`), Carbon                  | adopt              | `fieldCounter`, at the end of the label row, which is where Carbon puts it. The count is the consumer's, or `text-field`'s in wave 3.                        |
| Defaults set once for the whole application                         | Angular Material (`MAT_FORM_FIELD_DEFAULT_OPTIONS`), Chakra (recipe) | adopt            | `FieldDefaultsProvider` in React and `provideFieldDefaults()` in Angular, carrying `size`, `labelPlacement`, `requiredMark` and the two necessity words.     |
| Substituting the rendered element of a part                         | Base UI (`render`), Ark (`asChild`), Primer                        | adopt              | `render` in React; the Angular parts are directives on the consumer's own element, which is the same reach.                                                  |
| Reordering the parts                                                | Mantine (`inputWrapperOrder`)                                      | decline            | One order, and the field owns it: label, control, description, error. A field whose error is above its control is a field a reader meets after the fact, and the reorder exists in Mantine because its wrapper takes strings rather than elements. |
| Prefix and suffix inside the control's frame                        | Angular Material, Primer (`LeadingVisual`)                          | defer to `text-field` (wave 3) | An adornment sits inside the control's border, so it is the control's padding and click target, not the field's. The field-aware-controls design already records it as out of scope. |
| A floating label that animates into the control's border            | Angular Material (`floatLabel`, `appearance`)                      | decline            | A floating label is the control's frame, not the field's, and it removes the description's place. `text-field` owns the frame and does not float it.         |
| Native constraint validation matched per `ValidityState`            | Base UI (`match`), Spectrum (`validationBehavior="native"`)        | defer to `form` (wave 3, item 8) | The field is told it is invalid; deciding when it became invalid is submission and validation orchestration, which `docs/rebuild-order.md` assigns to `form`. |
| A `validate` callback and a validation mode                         | Base UI, Spectrum                                                  | defer to `form` (wave 3, item 8) | Same owner. A field holding a validator would hold form state, which PRD §5 lists as a non-goal.                                                            |
| `touched` and `dirty`                                               | Base UI                                                            | defer to `form` (wave 3, item 8) | Both describe the history of a value the field does not own.                                                                                                 |
| Contextual help beside the label                                    | Spectrum (`contextualHelp`)                                        | decline            | One implementation of eleven. A help trigger is a `button` opening a `popover` (wave 5); placed in the label row it would need its own click-target rules, and inside a `label` a click would focus the control instead of opening it. |

## 3. Differentiators

| Capability                                                                                   | Why this library can hold it                                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The severity is a word as well as a colour                                                   | The description and the error are `inline-message`, which writes `Error:` in clipped text before the sentence, from a table an application translates once. GOV.UK ships the idea hard-coded for errors; none of the other ten ships it at all. |
| A side label that reflows to a top label when the field is narrow                            | The field owns a `container-type: inline-size` container, so a field in a 240-pixel drawer stacks while the same field in a page grid stays beside its control. Spectrum's `labelPosition="side"` squeezes the label instead; nothing surveyed reflows. |
| Three colour schemes, three densities, and logical properties throughout                     | The label, the marker, the message and the counter all read control scales the theme restates per density, so a dense table's field shrinks whole rather than in parts.                                                                        |
| One decision for the whole application, in both bindings                                     | Only Angular Material ships application-wide defaults among the eleven, and only for Angular. The provider and the injection token carry the same four values.                                                                                  |
| The counter never moves the message                                                          | The counter sits in the label row's spare column, so a field whose count appears on the first keystroke does not gain a line. Angular Material puts it in the subscript, where it competes with the error for the same row.                     |
| A group that provides for its fields                                                         | `field-group` sets `size`, `labelPlacement`, `requiredMark`, `disabled` and `readOnly` for every field inside it through the same provider a whole application uses, so a disabled section is one attribute rather than one per field.          |

## 4. Gaps

| What a real product hits                                                             | What the family does                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The error arrives from a server after submit, and no reader is told                  | `fieldError` carries `inline-message`'s `live`, and the reference page states when to raise it. Fluent announces every validation message with `role="alert"`, which repeats an error the reader is already on; the field defaults to `off` and documents the choice. |
| The message arrives and the rest of the form jumps down                              | `fieldError reserve` holds one line box of its own leading open. Ten of the eleven leave the shift in place.                                                                                                     |
| A label of twelve words beside a 240-pixel control                                   | The side label wraps, stays start-aligned with the control's first line, and the container query stacks it below 320 pixels.                                                                                     |
| An unbreakable token in a description — a container digest, a host name              | `inline-message` already breaks it with `overflow-wrap: anywhere` and removes nothing from the DOM.                                                                                                              |
| A field disabled by the section around it while the field states nothing              | Every shared state is `undefined` rather than `false`, so a field defers to the group and the group to the application; an explicit value always wins.                                                            |
| A group whose legend is also the page heading                                        | `fieldGroupLegend` renders a `legend` that accepts a heading as its content, which is GOV.UK's recommendation and impossible in a family that takes the legend as a string.                                       |
| A required marker read aloud as “asterisk” on every field of a long form             | The marker is `aria-hidden`; the semantics reach the reader once, through `aria-required` on the control.                                                                                                        |

## 5. Delta against what shipped

`field` and `fieldset` shipped on schema 4, before the token foundation, the
state vocabulary and the identity rule.

| What shipped                                                        | What the field ships                                     | What this family will ship                                                                          |
| ------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `data-slotted-component` and `.slotted-field` class selectors       | —                                                        | `data-ui="field"` and `data-part`, with no class in the stylesheet.                                  |
| Four capabilities: `disabled`, `invalid`, `required`, `readOnly`    | plus placement, size, necessity, counter, defaults       | All of them.                                                                                          |
| `fieldDescription` and `fieldError` as bare paragraphs              | a message family with tone, glyph and severity word      | Both render `inline-message`.                                                                         |
| No size axis                                                        | Fluent ships three                                       | `sm`, `md`, `lg`, reading the control type scales.                                                    |
| No placement axis                                                   | four of eleven ship one                                  | `labelPlacement`, reflowing at 320 pixels.                                                            |
| No counter                                                          | two ship one                                             | `fieldCounter`.                                                                                        |
| No application-wide defaults                                        | one ships them                                           | Provider and injection token.                                                                          |
| `required` defaulting to `false`                                    | Base UI and Ark default it to unset                      | Every shared state is `undefined`, so a field defers to its group.                                     |
| `fieldset` as a separate family with `orientation`                  | —                                                        | `field-group`, with `orientation`, `legend`, description, error, and defaults for the fields inside.   |
