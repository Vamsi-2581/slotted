# Number Field — capability inventory

Produced from the field rather than from the family, before any design or code.
`docs/rebuild-order.md` lists `number-field` as **novo** in wave 3 with no scope
paragraph, so the scope is derived from `docs/component-features.md` § "Number
Field" and written back into the queue as part of this work.

Angular Material ships no number field: a numeric control there is `matInput`
on `<input type="number">`, which is the platform row above.

The ten split on the two decisions that shape everything else. **Element:**
only the platform uses `type="number"`; every library that formats a value uses
`type="text"`, because `type="number"` sanitizes anything it cannot parse to the
empty string and no locale's grouping separator survives it. **Role:** Zag and
PrimeNG apply `role="spinbutton"` with the full `aria-value*` set; React Aria
and Base UI strip the role — React Aria's source carries the reason in a
comment, "override the spinbutton role, we can't focus a spin button with VO" —
and replace it with `aria-roledescription` plus an assertive live announcement
of the value. Both decisions are taken in the design document, not here.

## 2. Table stakes

Every capability two or more of the ten ship. Verdicts are `adopt`, `adapt`,
`decline` or `defer to <family>`.

## 3. Differentiators

| Capability                                                        | Where it comes from                                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A parser that reads back everything the formatter can write        | Only React Aria and Zag ship one at all, and neither is usable outside its own binding. `@slotted/core/number` inverts `Intl.NumberFormat` from `formatToParts`: the locale's group separator, its decimal separator, its minus sign, its currency and unit affixes, and its numbering system. Pasting `R$ 1.480,00` into a `pt-BR` currency field yields `1480`, and pasting `١٤٨٠` into an `ar-EG` field yields the same number. |
| One arithmetic module both bindings share                          | Ant, Mantine and PrimeNG each wrote parsing inside a React or Angular component, so the two ecosystems cannot agree on what `1.234` means. Stepping, clamping, snapping, partial-number validation and formatting are framework-free here, tested once, and consumed by React and Angular unchanged.        |
| A cancellable request carrying its reason                          | Base UI reports nine reasons and lets a consumer refuse none of them. Here `onValueChange` receives a request that can be refused before anything commits, which is how a field that must confirm a quantity above stock is written without a controlled-mode dance.                                        |
| Three colour schemes, including `high-contrast`, and forced colours | None of the ten ships a high-contrast scheme. The stepper's glyphs are masks from the theme's own glyph scale, so they survive a palette the operating system replaces entirely, and the divider between the two halves keeps the stepper from reading as one block.                                        |
| Three densities                                                    | Nine of the ten ship size steps and no density. Here the frame, the type, the glyph and the stepper all read the control scales, so a dense table row shrinks the control whole rather than in parts — and the stepper still clears the 24-pixel minimum, corrected by the family the way `text-field` corrects its two buttons. |
| A stepper that mirrors without a second rule                       | The `split` layout is `flex` in logical order, so a right-to-left document puts decrement at the right and increment at the left with no `[dir]` selector and no flipped icon. PrimeNG and Carbon both write a physical layout.                                                                             |
| Field-aware with no wrapper                                        | `<NumberField />` inside a `<Field>` takes the identifier, the description, `aria-invalid`, `aria-required`, `disabled` and read-only without being asked. Base UI and Ark reach this only through their own field components; Carbon, Mantine and Ant reach it by owning the label themselves.             |
| Two first-class bindings                                           | `ControlValueAccessor` and DI-provided defaults in Angular, a context provider and `render` in React, from one contract, one stylesheet and one parser. PrimeNG is the only Angular row and it has no React sibling; the eight React rows have no Angular sibling.                                          |

## 4. Gaps

| What a real product hits                                       | The answer this family ships                                                                                                                                                                                                                                            |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A value the server refuses after it was typed                  | Controlled mode plus the cancellable request: the consumer holds the number, refuses the move until the write returns, and the reference page shows the optimistic version beside the pessimistic one.                                                                     |
| A quantity spun past the stock on hand                         | `max` disables the increment button at the bound and `clamp="blur"` returns the typed value to the range on commit. `clamp="none"` is there for the form that would rather show the error than move the reader's number.                                                    |
| A paste of the value as the reader's bank wrote it             | `R$ 1.480,00`, `1 480,00`, `1,480.00` and `١٬٤٨٠` all parse, because the parser is built from the same `Intl` parts the formatter is. Nothing of the ten handles more than its own configured separators.                                                                   |
| An IME composing digits                                        | The keystroke filter is skipped while a composition is in progress, so a Japanese full-width `１２３` is committed and then parsed rather than refused character by character.                                                                                               |
| A caret that jumps while typing                                | Nothing reformats the text while the reader is typing. The value is parsed on every input and the text is rewritten only on commit, so the caret is never restored from a position the family invented.                                                                     |
| A number longer than the control                               | The value ellipsises rather than clipping mid-glyph, the digits are tabular so nothing shifts as they are typed over, and the stepper never gives up width: the value is the part that can scroll.                                                                          |
| The steppers at 240 pixels and at `dense`                      | The drawn stepper is bounded by the frame's inner box the way `text-field`'s buttons are, and its hit area is recovered outside the paint to `--slotted-target-min`, so it stays hittable where the whole control is 24 pixels tall.                                        |
| A number field on a phone                                      | `inputMode` is `decimal` when the format admits a fraction and `numeric` when it does not, and it becomes `text` when the locale's minus sign or currency affix needs a key the numeric keypad does not offer.                                                               |
| Forced colours replacing the palette                           | The stepper's glyphs are masks over `currentcolor`, the frame keeps a `ButtonBorder` edge in the `plain` variant, and the disabled stepper is `GrayText` — all of it from the theme's own `forced-colors` block, with one rule the theme cannot write.                       |
| Reduced motion                                                 | The frame's border, ground and ring transition through motion-scale tokens the theme collapses to one millisecond. The auto-repeat is behaviour rather than animation and nothing loops, so nothing has to be stopped.                                                       |
| A field whose value is nought and whose field is required      | `null` and `0` are different values, `aria-required` is on the control, and the hidden input submits an empty string for `null` rather than `0`.                                                                                                                            |
