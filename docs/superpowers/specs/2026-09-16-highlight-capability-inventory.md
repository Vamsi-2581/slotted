# Highlight — inventário de capacidades

A folha partilhada `packages/styles/src/highlight/highlight.css` (onda 6, entregue
dentro de `combobox`) vira família: contrato, motor em `@slotted/core/highlight`,
binding React e Angular. O inventário sai do campo antes de qualquer código, como
`.claude/skills/component/references/capability.md` exige; o delta contra a folha
está em §5.

Três nomes escondem uma capacidade: `query` (Chakra), `highlight` (Mantine) e
`searchWords` (react-highlight-words) são o mesmo input. `findChunks` e
`sanitize` são as duas metades de um matcher substituível.

## 2. Table stakes

| Capacidade                                                   | Quem entrega                                    | Veredito         | Razão                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------ | ----------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Texto + query → trechos marcados em `<mark>`                 | Chakra, Mantine, rhw                            | adopt            | `text` e `query`; o texto original é a única fonte, dividido em runs por índices de code unit. Nenhum HTML é interpretado.                                                                                                                                                                         |
| Várias queries de uma vez                                    | Chakra, Mantine, rhw                            | adopt            | `query: string \| readonly string[]`. Intervalos de queries distintas que se sobrepõem ou se tocam fundem-se num run (rhw `combineChunks`).                                                                                                                                                       |
| Sem distinção de caixa                                       | Chakra (`ignoreCase`), Mantine, rhw             | adapt            | Comparação por `Intl.Collator` a `sensitivity: 'base'`, a mesma de `typeahead` e de `createFilter`: `resume` encontra `Resumé`, `ß` encontra `ss`. `sensitivity` é opção. Nenhuma das três entrega diacríticos; rhw delega ao `sanitize` do consumidor.                                          |
| Todas as ocorrências                                         | Mantine, rhw; Chakra por `matchAll`             | adopt            | Eixo `occurrences: all \| first`, padrão `all`. Custo para `combobox`, `select`, `multi-select` e `command-palette`: passam de um intervalo para todos; registado em §5.                                                                                                                             |
| Query vazia → texto sem marca                                | Chakra, Mantine, rhw                            | adopt            | Query vazia ou só espaço não marca; o DOM é o texto puro dentro da raiz. Exigido pelo guia §10.                                                                                                                                                                                                     |
| Caracteres especiais não são regex                           | Chakra, rhw (`autoEscape`)                      | adapt            | Nenhuma regex: o motor compara janelas do texto com o collator. `C++` e `a.b` são texto.                                                                                                                                                                                                           |
| Matcher substituível                                         | rhw (`findChunks`, `sanitize`)                  | adopt            | `matcher: (text, queries) => Range[]`; o resultado passa pela mesma normalização de intervalos. Um consumidor com busca fuzzy no servidor devolve os índices que o servidor devolveu.                                                                                                              |
| Intervalos explícitos                                        | rhw (`findChunks` devolve chunks)               | adopt            | `ranges: readonly [start, end][]`; vence `query`. Exigido pelo guia §10.                                                                                                                                                                                                                           |
| Estilo da marca substituível                                 | Chakra (`styles`), Mantine (`highlightStyles`, `color`) | adapt      | Tokens `--slotted-highlight-{background, color, rule-color, tint-opacity, disabled-background}` já existentes, mais os de `current` (§3). Nenhum objeto de estilo entra no contrato (guia §2.4).                                                                                                    |
| Elemento raiz substituível                                   | Chakra (`as`/`asChild`), Mantine (`component`)  | adopt            | React: `render`; Angular: componente com seletor de atributo `[slHighlight]`, aplicado ao elemento que o consumidor já tem. Em `combobox` a raiz é o próprio `span[data-part='label']` do item.                                                                                                     |
| Elemento da marca substituível                               | rhw (`highlightTag`)                            | decline          | O elemento é `mark`: é o que carrega a semântica e o par `Mark`/`MarkText` sob cores forçadas. O que rhw resolve com `highlightTag` (um styled component) esta biblioteca resolve com os tokens acima e com `[data-ui='highlight'] [data-part='match']`.                                          |
| Só palavras inteiras                                         | Chakra (`exactMatch`)                           | decline          | Uma implementação. O consumidor escreve o matcher: `matcher: (text, q) => matchRanges(text, q).filter(([s, e]) => isWordBoundary(text, s) && isWordBoundary(text, e))` — três linhas sobre o que a família exporta.                                                                                  |
| Match ativo (n de m)                                         | rhw (`activeIndex`, `activeClassName`)          | adopt            | `current: number` → `data-current` na marca correspondente. Uma ocorrência; ver §3.                                                                                                                                                                                                                |

## 3. Diferenciadores

| Capacidade                                              | Origem                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A marca do mesmo collator que o filtro                  | Chakra e Mantine comparam por regex com `i`; rhw pelo `sanitize` do consumidor. Aqui o motor é o `scan` que `createFilter` e `createRanker` já usam, movido para `@slotted/core/highlight` e importado por `collection/filter`. Um item que passa no filtro mostra a marca que o filtro encontrou.              |
| A marca não altera nenhuma métrica da palavra           | Mantine aplica `padding` e `border-radius` ao `mark`; uma marca que muda a cada tecla move o rótulo. CB6: `font-weight`, `letter-spacing`, `padding` herdados ou zero; teste `changes no metric of the word it marks`.                                                                                        |
| Três esquemas, cores forçadas, linha desativada         | Tinta mixada de `accent-text` a 7,5 % com a razão calculada nos três esquemas (comentário da folha); `Mark`/`MarkText` sob `forced-colors`; dentro de `[data-disabled]` a marca cede a cor e mantém a régua.                                                                                                  |
| Match corrente para "localizar na página"               | rhw é a única com `activeIndex`. `current` é o índice da ocorrência que uma barra de busca aponta; a marca leva `data-current` e a folha pinta-a acima das outras. A família não move o índice — não tem teclado — por isso `current` é estado sem modelo, como `list-item` e `timeline` declaram.            |
| Intervalos ajustados a grafemas                         | Nenhuma das três. Um intervalo que corta um par substituto ou um cluster (`🇧🇷`, `é` decomposto, ZWJ) produz um `mark` com metade de um caractere. `normalizeRanges` estende cada limite ao grafema por `Intl.Segmenter`; sem `Segmenter`, ao code point.                                                       |
| Dois bindings sobre um motor                            | React `Highlight` com `render`; Angular `[slHighlight]` sobre o elemento do host; os runs vêm de `splitRanges` nos dois, por isso o limite de cada run é decidido uma vez.                                                                                                                                    |

## 4. Gaps

| Caso                                                                         | Resposta                                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Queries que se sobrepõem (`an`, `na` em `banana`)                            | Intervalos ordenados e fundidos antes de dividir; um run por trecho contíguo. Nenhum `mark` aninhado, nenhum run vazio.                                                                                                                                                       |
| Intervalos fora do texto, invertidos ou vazios                               | `normalizeRanges` recorta a `[0, text.length]`, troca `start > end`, descarta `start === end`. Um intervalo vindo de um servidor desatualizado degrada para nenhuma marca, não para uma exceção.                                                                              |
| Rótulo de 10 000 caracteres com query de um caractere                        | O scan é `O(n · 3)` comparações por query; a 10 000 caracteres são 30 000 `compare` — medido no teste do motor abaixo de 50 ms. Sem limite artificial; a folha usa `box-decoration-break: clone`, por isso mil marcas numa linha que quebra são mil pares de caixas corretas. |
| Texto que não é string (ícone, JSX)                                          | `text` é `string`. O host decide: `combobox` só marca quando tem `text`, e um item cujo rótulo é composição fica sem marca, como hoje.                                                                                                                                         |
| Leitor de tela verboso                                                       | `mark` não é anunciado por padrão (MDN); JAWS e NVDA anunciam quando o utilizador o ativa. A família não injeta `::before` textual — cinco marcas num rótulo seriam dez anúncios. O `mark` fica com a semântica; a decisão está no contrato.                                  |
| RTL e bidi                                                                   | `mark` é inline e não abre um embedding; os índices são lógicos, por isso um trecho de texto árabe marca-se no mesmo lugar em `ltr` e `rtl`. Cena `rtl` no harness.                                                                                                             |
| SSR                                                                          | Motor puro sobre strings, sem ids, sem medição; o mesmo DOM no servidor e no cliente. `Intl.Segmenter` existe no Node 16+.                                                                                                                                                    |
| `current` fora do intervalo                                                  | Nenhuma marca leva `data-current`; nenhum erro.                                                                                                                                                                                                                                |

## 5. O delta contra a folha

| O que a folha tinha                                           | O que o campo entrega                    | O que a família entrega                                                                                                                                                              |
| ------------------------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `data-ui='highlight'` no próprio `mark`, sem raiz             | uma raiz que segura o texto              | Raiz `[data-ui='highlight'][data-part='root']` no elemento que segura o texto; a marca é `[data-part='match']` dentro dela. O seletor da folha muda de `[data-ui='highlight']` para `[data-ui='highlight'] [data-part='match']`. |
| Um intervalo por query, o primeiro (`matchRanges`)            | todas as ocorrências                     | `occurrences: all` por padrão. Os quatro hosts que hoje marcam passam a marcar todas as ocorrências.                                                                                 |
| Runs decididos em `collection/filter.ts`                      | motor próprio                            | `@slotted/core/highlight`: `matchRanges`, `normalizeRanges`, `splitRanges`, `createMatcher`. `collection/filter.ts` importa o scan daqui e reexporta `matchRanges` e `splitByMatch` sem mudar assinatura. |
| Sem binding: cada host escreve o `mark`                       | um componente                            | React `Highlight`; Angular `[slHighlight]`. `combobox`, `select`, `multi-select` e `command-palette` (React e Angular) passam a usar o binding. `listbox` deixa de importar a folha: a família importa a sua. |
| Sem estado próprio                                            | `activeIndex`                            | `current` e `disabled` como estados declarados; `disabled` também herdado de `[data-disabled]` acima.                                                                                 |
| Sem contrato                                                  | —                                        | `specs/components/highlight/contract.json`; o bloco `mark` de `combobox` passa a apontar para a família.                                                                              |

`multi-select` e `command-palette` escrevem o mesmo `mark` à mão nos dois
bindings e migram na mesma sessão: a folha muda de seletor uma vez e nenhum
host fica sem tinta. `tree` escreve um `<mark>` sem identificador e sem folha —
nunca foi pintado — e fica registado em `docs/build-order.md` como reabertura.
`menu` está em edição por outra sessão (`context-menu hover-card`); a sua
importação da folha é removida quando essa sessão fechar, registado no mesmo
lugar.
